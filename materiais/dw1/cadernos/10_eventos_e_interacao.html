1. Programação Orientada a Eventos na Interface Web #

Diferente de um script de linha de comando que roda do início ao fim e termina, uma página Web funciona de forma orientada a eventos (Event-Driven). O navegador permanece aguardando ações da pessoa usuária: um clique no botão '+ Adicionar', uma tecla digitada na busca ou o envio de um formulário de cupom.

Com o método elemento.addEventListener(tipoDoEvento, funcaoOuvinte), conectamos funções JavaScript que reagem instantaneamente a cada interação na Vitrine Lojas Blue.

POR QUE EVENT.PREVENTDEFAULT() É OBRIGATÓRIO EM FORMULÁRIOS JS?

Por padrão histórico do HTML, quando um usuário clica em um botão type="submit" ou aperta Enter dentro de um <form>, o navegador tenta enviar os dados para outra URL e recarrega a página inteira, apagando tudo que o JavaScript calculou! Chamar event.preventDefault() na primeira linha do ouvinte de submit cancela esse recarregamento.

2. addEventListener, Leitura de .value e preventDefault() #

Veja como combinamos o evento input (para recálculo em tempo real) e o evento submit (para validação de cupom sem recarregar a página):

JAVASCRIPT
const campoQtd = document.querySelector("#qtd-item");
const saidaSubtotal = document.querySelector("#valor-subtotal");
const formCupom = document.querySelector("#form-cupom");
const campoCupom = document.querySelector("#input-cupom");
const msgFeedback = document.querySelector("#msg-cupom");

const PRECO_UNITARIO = 140;

// 1. Recalcular imediatamente a cada alteração no input numérico
campoQtd.addEventListener("input", (event) => {
  // Atenção: .value é sempre String! Convertemos com Number()
  const quantidade = Math.max(1, Number(event.target.value) || 1);
  const total = quantidade * PRECO_UNITARIO;
  saidaSubtotal.textContent = `R$ ${total.toFixed(2).replace(".", ",")}`;
});

// 2. Validar formulário sem recarregar a página
formCupom.addEventListener("submit", (event) => {
  event.preventDefault(); // Impede o reload da página!

  const codigo = campoCupom.value.trim().toUpperCase();
  if (codigo === "BLUE10") {
    msgFeedback.textContent = "Cupom BLUE10 aplicado: 10% de desconto!";
    msgFeedback.className = "feedback sucesso";
  } else {
    msgFeedback.textContent = "Cupom inválido ou expirado.";
    msgFeedback.className = "feedback erro";
  }
});

A ARMADILHA DA CONCATENAÇÃO: '2' + 1 = '21'

Qualquer valor lido de input.value chega ao JavaScript como texto (String), mesmo que o campo seja type="number"! Se você somar campoQtd.value + 1 sem converter com Number(campoQtd.value), o número '2' virará '21' em vez de 3.

4. Desafio interativo e quadro-síntese #

Resolva as três rodadas interativas abaixo para consolidar os conceitos centrais deste caderno antes de abrir os arquivos práticos:

Conceito-chaveRegra prática na Vitrine Lojas Blue
Evite onclick="..." no HTMLMantenha o HTML limpo e concentre todos os ouvintes no JavaScript usando addEventListener.
Higienização de textoSempre use .trim() ao ler campos de texto para remover espaços em branco acidentais no início ou no fim.
Acessibilidade no formulárioOuvir o evento submit no <form> (em vez de apenas click no botão) garante que o envio funcione também quando o usuário pressiona a tecla Enter.
