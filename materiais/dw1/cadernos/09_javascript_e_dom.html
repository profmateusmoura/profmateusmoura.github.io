1. Dando Vida à Página: O JavaScript encontra a Árvore DOM

Até agora, nossa vitrine da Lojas Blue possui estrutura semântica (HTML5) e layout responsivo elegante (CSS3), mas ainda é estática. Para aplicar um cupom de desconto, destacar um produto selecionado, alternar o tema visual ou somar itens da sacola, entramos na terceira camada da Web: o JavaScript no navegador.

Quando o navegador carrega o HTML, ele expõe um objeto global chamado document. Esse objeto é a porta de entrada para a árvore DOM (Document Object Model): cada tag HTML se transforma em um objeto JavaScript vivo que podemos localizar, ler e modificar instantaneamente sem recarregar a página.

Separação de responsabilidades: JS muda classes, CSS define o visual!

Em vez de escrever 8 linhas de elemento.style.backgroundColor = ... no JavaScript, crie uma classe .em-oferta no seu CSS e use apenas elemento.classList.toggle('em-oferta') no JavaScript. Seu código fica limpo, fácil de manter e fiel à arquitetura Web.

2. querySelector, textContent, dataset e classList

Veja como o JavaScript localiza elementos usando os mesmos seletores do CSS, lê atributos data-* do HTML e atualiza a interface:

JAVASCRIPT · Cenário Vitrine Lojas Blue 
// HTML: <article id="card-1" class="card" data-preco="250" data-categoria="Periféricos">
//         <h3 class="titulo">Teclado Mecânico</h3>
//         <p class="preco">R$ 250,00</p>
//       </article>

// 1. Selecionar elementos no DOM usando seletores CSS
const card = document.querySelector("#card-1");
const precoEl = card.querySelector(".preco");

// 2. Ler dados embutidos no HTML via atributos data-* (dataset)
const precoBase = Number(card.dataset.preco); // 250
const categoria = card.dataset.categoria;     // "Periféricos"

// 3. Calcular 10% de desconto no PIX e atualizar o texto com segurança
const precoPix = precoBase * 0.90;
precoEl.textContent = `R$ ${precoPix.toFixed(2).replace(".", ",")} no PIX`;

// 4. Alternar classe CSS de destaque no card
card.classList.add("destaque-pix");

Segurança Web: textContent vs. innerHTML

Nunca use innerHTML para exibir textos digitados pelo usuário (como um termo de busca ou nome de cliente), pois se alguém digitar tags <script> ou <img onerror=...>, o navegador executará código malicioso (ataque XSS). Use sempre textContent para textos!
