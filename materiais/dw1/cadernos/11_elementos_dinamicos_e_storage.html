1. Interfaces Dirigidas por Dados (Data-Driven UI) e Persistência

Em uma loja real com dezenas ou centenas de produtos, nós não copiamos e colamos 100 blocos <article> manualmente no HTML. Em vez disso, os produtos vivem em uma estrutura de dados (um Array de Objetos), e uma função JavaScript percorre esse array gerando os elementos do DOM dinamicamente.

E o que acontece quando a cliente adiciona 3 produtos na sacola da Lojas Blue e atualiza a página (F5)? Se os dados estiverem apenas em uma variável na memória RAM, tudo se perde! Para que a sacola e as preferências sobrevivam ao fechamento da aba, usamos a Web Storage API (localStorage) combinada com serialização JSON.

A regra do localStorage: tudo lá dentro é String!

O localStorage só sabe guardar pares de chave e valor em formato de texto. Por isso, sempre convertemos nossos arrays/objetos para texto antes de salvar usando JSON.stringify(dados) e fazemos o caminho inverso ao ler usando JSON.parse(textoSalvo).

2. createElement, appendChild, filter() e localStorage JSON

Observe o ciclo completo de ler uma lista salva no localStorage, renderizar os elementos no DOM com segurança e persistir novas adições:

JAVASCRIPT · Cenário Vitrine Lojas Blue 
const CHAVE_STORAGE = "lojas_blue_favoritos";
const listaUl = document.querySelector("#lista-favoritos");

// 1. Recuperar estado salvo no navegador (ou iniciar array vazio)
let favoritos = JSON.parse(localStorage.getItem(CHAVE_STORAGE) || "[]");

function salvarEstado() {
  localStorage.setItem(CHAVE_STORAGE, JSON.stringify(favoritos));
}

// 2. Renderizar a interface a partir do array de dados
function renderizarFavoritos() {
  listaUl.innerHTML = ""; // Limpa antes de redesenhar para não duplicar!

  favoritos.forEach((produto) => {
    const li = document.createElement("li");
    li.className = "item-favorito";
    li.textContent = `${produto.nome} — R$ ${produto.preco.toFixed(2)}`;
    listaUl.appendChild(li);
  });
}

// 3. Adicionar novo item, salvar e re-renderizar
function adicionarFavorito(nome, preco) {
  favoritos.push({ id: Date.now(), nome, preco });
  salvarEstado();
  renderizarFavoritos();
}

O erro '[object Object]' no localStorage

Se você fizer localStorage.setItem('sacola', meuArray) esquecendo o JSON.stringify(), o JavaScript converterá o objeto de forma ingênua para a string literal "[object Object]", destruindo os dados e gerando erro de sintaxe quando o JSON.parse() tentar ler!
