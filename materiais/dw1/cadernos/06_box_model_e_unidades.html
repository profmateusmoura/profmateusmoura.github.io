1. Tudo na Web é uma Caixa Retangular #

Para o motor de renderização do navegador, cada elemento HTML da Lojas Blue — seja um título, uma foto de produto, uma pílula de categoria ou um botão — é desenhado como uma caixa retangular composta por quatro camadas concêntricas conhecidas como CSS Box Model.

De dentro para fora, temos: 1) Content (Conteúdo), onde ficam o texto e a imagem; 2) Padding (Preenchimento interno), o respiro entre o conteúdo e a borda, que recebe a cor de fundo do card; 3) Border (Borda), a moldura visível da caixa; e 4) Margin (Margem externa), o espaço transparente que afasta um card dos seus vizinhos.

POR QUE TODO PROJETO MODERNO COMEÇA COM BOX-SIZING: BORDER-BOX?

No comportamento padrão antigo (content-box), se você define width: 260px e adiciona padding: 20px e border: 2px, o card cresce para 304px (260 + 40 + 4) e quebra o layout! Com box-sizing: border-box, os 260px já incluem padding e borda, mantendo o tamanho externo travado e previsível.

2. Reset Universal, Unidades Relativas e Position #

Veja o padrão profissional de configuração do Box Model e como ancoramos um selo de desconto no canto superior direito de um card:

CSS
/* 1. Reset universal de Box Sizing */
*, *::before, *::after {
  box-sizing: border-box;
}

/* 2. Card como referência de posicionamento (relative) */
.card-produto {
  position: relative;
  width: 100%;
  max-width: 280px;
  padding: 1.25rem;       /* 20px quando html = 16px */
  border: 1px solid #cbd5e1;
  border-radius: 0.75rem; /* 12px */
  margin-bottom: 1rem;
  background-color: #ffffff;
}

/* 3. Badge ancorado no canto superior direito do card (absolute) */
.badge-desconto {
  position: absolute;
  top: 0.75rem;
  right: 0.75rem;
  display: inline-block;
  padding: 0.25rem 0.6rem;
  background-color: #15803d;
  color: #ffffff;
  font-size: 0.75rem;
  font-weight: 700;
  border-radius: 999px;
}
Propriedade / ConceitoOpções PrincipaisComo funciona na prática
box-sizingcontent-box vs. border-boxEm border-box, width engloba conteúdo + padding + border
Unidades de medidarem, em, %, vw/vh, pxrem escala a partir do <html> (acessível); px é ideal para bordas finas
display clássicoblock, inline, inline-blockinline (como <span>) ignora width/height; inline-block aceita dimensões mantendo fluxo em linha
positionstatic, relative, absolute, stickyabsolute se guia pelo ancestral posicionado (relative) mais próximo; sticky fixa no topo ao rolar

3. Simulador Visual Ao Vivo: Matemática das Camadas do Box Model #

Ajuste os controles deslizantes de width, padding, border e margin e alterne o botão box-sizing para observar a diferença imediata na largura real da caixa:

SELO ABSOLUTE 'FUGINDO' PARA O CANTO DA JANELA INTEIRA

Se você aplicar position: absolute; top: 10px; right: 10px; em um selo e esquecer de colocar position: relative; no card pai, o navegador subirá toda a árvore DOM sem achar referência e prenderá o selo no canto da página inteira (<body>).

4. Desafio interativo e quadro-síntese #

Resolva as três rodadas interativas abaixo para consolidar os conceitos centrais deste caderno antes de abrir os arquivos práticos:
