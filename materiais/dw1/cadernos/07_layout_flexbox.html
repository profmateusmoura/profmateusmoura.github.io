1. Adeus gambiarras com float: o poder do Flexbox

Como colocar a logomarca da Lojas Blue à esquerda, a barra de busca no centro e o botão da sacola à direita, todos perfeitamente alinhados na vertical? E como garantir que três cards de produto lado a lado tenham a mesma altura e mantenham o botão 'Adicionar à Sacola' colado na base, mesmo quando um produto tem um título de 3 linhas e o outro tem apenas 1 linha?

O CSS Flexbox (Flexible Box Layout) foi projetado exatamente para resolver layouts unidimensionais (uma linha ou uma coluna por vez) com distribuição inteligente de espaço e alinhamento automático.

Regra mental n.º 1 do Flexbox: quem é o Eixo Principal?

Quando flex-direction: row (padrão), o eixo principal é horizontal (controlado por justify-content) e o eixo transversal é vertical (controlado por align-items). Quando mudamos para flex-direction: column, os eixos giram 90 graus: justify-content passa a atuar na vertical e align-items na horizontal!

2. Navbar, Pílulas de Filtro e Cards de Altura Igualada

Veja os dois padrões mais importantes de Flexbox na Vitrine Lojas Blue: o cabeçalho horizontal e o card vertical com botão fixo na base:

CSS · Cenário Vitrine Lojas Blue 
/* 1. Barra de navegação horizontal alinhada */
.navbar-blue {
  display: flex;
  flex-direction: row;
  justify-content: space-between; /* extremos horizontais */
  align-items: center;            /* centralizado verticalmente */
  flex-wrap: wrap;
  gap: 1rem;
  padding: 1rem 1.5rem;
}

/* 2. Card vertical com botão sempre colado na base */
.card-produto {
  display: flex;
  flex-direction: column;
  gap: 0.5rem;
  padding: 1.25rem;
}

.card-produto .btn-comprar {
  margin-top: auto; /* absorve toda a sobra vertical acima do botão! */
}

Tabela Comparativa e Referência Técnica

Propriedade FlexboxOnde aplicaValores mais usados e efeito
display: flexContainer PaiTransforma os filhos diretos em Flex Items organizados no eixo principal
flex-directionContainer Pairow (linha →), column (coluna ↓), row-reverse, column-reverse
justify-contentContainer PaiAlinha no Eixo Principal: flex-start, center, space-between, space-evenly
align-itemsContainer PaiAlinha no Eixo Transversal: stretch (padrão), center, flex-start, flex-end
flex-wrap + gapContainer Paiwrap permite quebrar linha quando falta espaço; gap define o espaçamento exato entre itens
flex: 1 / margin-top: autoFlex Item (Filho)flex: 1 faz o item crescer para ocupar a sobra; margin-top: auto empurra para a base

display: flex afeta apenas os filhos diretos!

Ao aplicar display: flex em uma <section>, apenas os elementos filhos de primeiro nível viram Flex Items. Os elementos 'netos' (como textos dentro de um <article>) continuam no fluxo normal a menos que o próprio <article> também receba display: flex.
