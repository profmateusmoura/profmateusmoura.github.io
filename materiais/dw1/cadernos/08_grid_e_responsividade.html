1. Grades Bidimensionais e Design Responsivo Multi-Tela

Enquanto o Flexbox brilha ao alinhar elementos em uma única direção (como o topo da loja ou o interior de um card), a vitrine principal de produtos da Lojas Blue precisa controlar colunas e linhas simultaneamente com larguras rigorosamente alinhadas. Esse é o território do CSS Grid Layout.

Além disso, mais de 65% dos acessos a lojas virtuais vêm de smartphones. Com a combinação de CSS Grid fluido e Media Queries (@media), o mesmo código HTML se adapta de 1 coluna no celular para 2 colunas no tablet e 4 colunas no monitor widescreen sem barra de rolagem horizontal.

A linha mágica do CSS Grid moderno

A declaração grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); instrui o navegador a criar automaticamente quantas colunas de no mínimo 220px couberem na tela e a dividir o espaço restante em partes iguais (1fr)!

2. CSS Grid (fr, minmax, span) e Media Queries (@media)

Veja como estruturamos a grade de produtos da Lojas Blue com suporte a card em destaque e adaptação responsiva para telas menores:

CSS · Cenário Vitrine Lojas Blue 
/* 1. Grade de produtos auto-responsiva */
.grade-vitrine {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1.25rem;
}

/* 2. Card promocional ocupando 2 colunas no desktop */
.card-destaque {
  grid-column: span 2;
}

/* 3. Imagens fluidas que nunca estouram o card */
img {
  max-width: 100%;
  height: auto;
  display: block;
}

/* 4. Media Query para telas até 640px (Smartphones) */
@media (max-width: 640px) {
  .card-destaque {
    grid-column: span 1; /* volta a ocupar 1 coluna no celular */
  }
}

Se você definir grid-column: span 2 em um card e não voltar para span 1 em telas pequenas (mobile), a grade será forçada a manter 2 colunas espremidas no celular. Sempre revise o comportamento em viewports de 360px!
