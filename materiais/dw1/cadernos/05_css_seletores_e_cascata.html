1. Dando Identidade Visual à Vitrine Lojas Blue #

Nos quatro primeiros cadernos, construímos uma estrutura HTML5 semântica, acessível e bem organizada. Agora entra em cena o CSS (Cascading Style Sheets) para transformar essa estrutura na identidade visual da Lojas Blue: paleta de azuis profundos, contrastes claros para preços, botões convidativos e hierarquia tipográfica limpa.

O nome Cascading (Em Cascata) não é por acaso: um mesmo elemento HTML pode receber regras vindas do navegador, de um seletor de tag, de uma classe utilitária e de um ID. Entender como o navegador desempata essas regras por meio da Especificidade e da Herança é o que separa quem 'chuta propriedades até funcionar' de quem domina o CSS.

DESIGN TOKENS COM VARIÁVEIS CSS (:ROOT)

Em vez de repetir o código hexadecimal #1d4ed8 em 40 lugares diferentes, declaramos variáveis globais no seletor :root (como --blue-primaria: #1d4ed8;) e as reutilizamos com var(--blue-primaria). Precisou ajustar o tom da marca ou criar modo escuro? Basta alterar uma única linha!

2. Seletores, Especificidade (a, b, c) e Tipografia #

Analise como organizamos os tokens da marca no :root, estilizamos classes reutilizáveis e garantimos estados interativos acessíveis:

CSS
:root {
  --cor-primaria: #1d4ed8;
  --cor-destaque: #15803d;
  --cor-texto: #0f172a;
  --cor-fundo-card: #ffffff;
}

body {
  font-family: system-ui, -apple-system, sans-serif;
  color: var(--cor-texto);
  line-height: 1.6;
}

/* Seletor de Classe: Especificidade (0, 1, 0) */
.preco-atual {
  color: var(--cor-primaria);
  font-size: 1.25rem;
  font-weight: 800;
}

/* Seletor de ID: Especificidade (1, 0, 0) — vence a classe */
#oferta-relampago {
  color: var(--cor-destaque);
}

/* Estados interativos para mouse (:hover) e teclado (:focus-visible) */
.btn-comprar:hover,
.btn-comprar:focus-visible {
  background-color: #1e40af;
  outline: 3px solid #93c5fd;
  outline-offset: 2px;
}

Classe / Pseudo-classe / Atributo.card, :hover, [type="email"](0, 1, 0)Componentes reutilizáveis (padrão principal em projetos reais)

POR QUE EVITAR O USO DE !IMPORTANT?

Adicionar !important quebra a cascata natural do CSS e torna futuras manutenções um cabo de guerra. Em vez de usar !important, verifique no DevTools qual seletor mais específico está vencendo e ajuste a arquitetura das suas classes.

4. Desafio interativo e quadro-síntese #

Resolva as três rodadas interativas abaixo para consolidar os conceitos centrais deste caderno antes de abrir os arquivos práticos:

Conceito-chaveRegra prática na Vitrine Lojas Blue
Herança CSSPropriedades tipográficas (color, font-family, line-height) são herdadas pelos filhos; propriedades de caixa (border, padding, margin) não são herdadas.
Desempate na Cascata1º Maior especificidade vence → 2º Em caso de empate de especificidade, vence a regra declarada por último no código.
Acessibilidade de FocoNunca remova o contorno de foco (outline: none) sem oferecer um estilo claro em :focus-visible.
