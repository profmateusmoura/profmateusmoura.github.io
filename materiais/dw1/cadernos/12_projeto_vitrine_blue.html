1. A Grande Convergência: HTML5 + CSS3 + JavaScript #

Chegamos ao coroamento da disciplina de Desenvolvimento Web I! Ao longo dos 11 cadernos anteriores, construímos peça por peça os fundamentos da plataforma Web. Agora vamos integrar todas essas camadas em uma aplicação completa, funcional e responsiva: a Vitrine Interativa Lojas Blue.

O segredo para que uma aplicação interativa não vire um emaranhado confuso de código é adotar uma Arquitetura de Fluxo Unidirecional de Estado: 1) mantemos um objeto central estado com os dados atuais (categoria selecionada, texto de busca, cupom e itens da sacola); 2) cada evento do usuário altera apenas esse estado e salva no localStorage; 3) uma função central renderizarTudo() redesenha a grade, os contadores, a barra de frete grátis e o resumo financeiro.

FONTE ÚNICA DE VERDADE (SINGLE SOURCE OF TRUTH)

Nunca tente somar o total da compra lendo textos soltos da tela com querySelector. Faça todos os cálculos matemáticos (subtotal, desconto de 10% do cupom BLUE10 e meta de R$ 250,00 para frete grátis) diretamente sobre o array estado.sacola usando reduce() e depois reflita o resultado no DOM!

2. Arquitetura Completa do Motor da Vitrine Lojas Blue #

Estude o núcleo arquitetural em JavaScript que coordena os filtros combinados, a sacola de compras e o fechamento financeiro:

JAVASCRIPT
const META_FRETE_GRATIS = 250;

const estado = {
  categoria: "Todos",
  busca: "",
  cupomAtivo: false,
  sacola: JSON.parse(localStorage.getItem("blue_sacola") || "[]")
};

// 1. Filtragem combinada (Categoria E Busca Textual)
function obterProdutosVisiveis(catalogo) {
  return catalogo.filter((prod) => {
    const bateCategoria = estado.categoria === "Todos" || prod.categoria === estado.categoria;
    const bateBusca = prod.nome.toLowerCase().includes(estado.busca.toLowerCase());
    return bateCategoria && bateBusca;
  });
}

// 2. Cálculo financeiro consolidado com reduce()
function calcularResumoSacola() {
  const subtotal = estado.sacola.reduce((soma, item) => soma + item.preco * item.qtd, 0);
  const desconto = estado.cupomAtivo ? subtotal * 0.10 : 0;
  const totalLiquido = subtotal - desconto;
  const faltaParaFrete = Math.max(0, META_FRETE_GRATIS - totalLiquido);

  return { subtotal, desconto, totalLiquido, freteGratis: faltaParaFrete === 0, faltaParaFrete };
}

4. Desafio interativo e quadro-síntese #

Resolva as três rodadas interativas abaixo para consolidar os conceitos centrais deste caderno antes de abrir os arquivos práticos:

Conceito-chaveRegra prática na Vitrine Lojas Blue
Ciclo de AtualizaçãoEvento do Usuário → Atualiza estado → Salva no localStorage → Chama renderizarTudo().
Incremento inteligente na sacolaAo adicionar um produto, verifique com sacola.find(i => i.id === id): se já existir, apenas some +1 em item.qtd; se não existir, faça sacola.push({ ...produto, qtd: 1 }).
Remoção limpaSe a quantidade de um item cair para 0 ao clicar no botão -, remova-o do array com estado.sacola = estado.sacola.filter(i => i.id !== id).
