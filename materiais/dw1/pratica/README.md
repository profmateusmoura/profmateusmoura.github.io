# Prática Intensiva de Desenvolvimento Web I (DW1) — Lojas Blue

Este pacote reúne **48 exemplos comentados** e **72 exercícios práticos** (120 arquivos `.html` autocontidos) distribuídos nos **12 tópicos** de **Desenvolvimento Web I (HTML5, CSS3 e JavaScript DOM)**.

## Como estudar na IDE e no Navegador

1. Abra a pasta no **VS Code**.
2. Em cada tópico (`01_web_e_documento_html` até `12_projeto_vitrine_blue`), leia e abra primeiro os arquivos da pasta `exemplos/` no navegador (duplo-clique ou extensão *Live Server*).
3. Use as ferramentas do desenvolvedor (`F12` → abas *Elements / Inspecionar*, *Styles* e *Console*) para observar como cada tag, regra CSS e script funciona.
4. Em seguida, abra os arquivos da pasta `exercicios/` no VS Code, leia o enunciado no comentário inicial e complete a solução.

Consulte [ORDEM_DE_ESTUDO.md](ORDEM_DE_ESTUDO.md) para a trilha completa e [ATIVIDADES_POR_TIPO.md](ATIVIDADES_POR_TIPO.md) para navegar por modalidade de exercício.
