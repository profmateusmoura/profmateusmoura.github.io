Identidade, representação e dados

Distinguir ser o mesmo objeto de possuir os mesmos valores.

COMO ESTUDAR

Leia as explicações em ordem, acompanhe o código e só depois abra os exemplos completos no ZIP. Não é preciso ter usado classes antes de começar esta trilha.

1. is pergunta sobre identidade #

Duas variáveis podem apontar para o mesmo objeto. Nesse caso, is retorna verdadeiro. Duas construções independentes podem guardar os mesmos valores e ainda serem objetos diferentes. Essa distinção reaparece quando coleções guardam referências, quando compartilhamos um produto e quando fazemos cópias.

Igualdade com == depende do comportamento definido para o tipo. Em classes comuns sem personalização, não presuma que todos os atributos serão comparados automaticamente. É preciso conhecer o contrato da classe.

2. dataclass reduz repetição em modelos de dados #

dataclass pode gerar inicialização, representação e igualdade a partir dos campos declarados. Isso é útil para objetos cujo papel principal é representar valores. A anotação de tipo documenta a intenção, mas não valida automaticamente cada argumento em execução.

O exemplo utiliza frozen=True para impedir atribuições normais posteriores aos campos. Isso não significa imutabilidade profunda de qualquer objeto interno. Aqui os campos são inteiros e string, o que mantém o modelo simples.

3. Escolher o significado da igualdade #

Uma etiqueta pode ser considerada igual a outra quando código e nome são iguais. Uma entidade de negócio pode precisar de outra regra, baseada em identidade persistente. Não aplique igualdade por todos os campos sem pensar no problema.

Use uma representação legível para depurar, mas não trate repr como formato de armazenamento durável. No próximo caderno, converteremos explicitamente entre o domínio e um documento JSON com campos definidos.

4. Um exemplo acompanhado

O programa abaixo é completo e independente. Antes de executar, procure o estado inicial e a operação que produz o resultado. Os comentários documentam as responsabilidades.

Python
from dataclasses import dataclass


@dataclass(frozen=True)
class Etiqueta:
    """Valor composto por código e nome; tipos anotados não validam entradas."""
    codigo: int
    nome: str

a = Etiqueta(1, "Shampoo")
b = Etiqueta(1, "Shampoo")
print(a == b)
print(a is b)
Saída
True
False

Compare outras duas situações

Os trechos seguintes usam as mesmas definições acima. Cada um começa com novos objetos; não reutilize o estado de uma execução anterior.
