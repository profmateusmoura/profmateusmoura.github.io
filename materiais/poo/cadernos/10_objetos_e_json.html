Objetos, arquivos e JSON

Separar o modelo de objetos do formato utilizado para trocar dados.

COMO ESTUDAR

Leia as explicações em ordem, acompanhe o código e só depois abra os exemplos completos no ZIP. Não é preciso ter usado classes antes de começar esta trilha.

1. JSON não guarda uma instância Python diretamente #

JSON representa números, textos, booleanos, null, listas e objetos de chave textual. Uma instância de Produto não é automaticamente convertida por json.dumps. Defina uma representação de dados e converta explicitamente.

Um adaptador sabe transformar o objeto em campos simples e reconstruí-lo. O domínio continua responsável por aceitar apenas estados válidos. Não copie o dicionário externo diretamente para __dict__ como se qualquer campo recebido fosse confiável.

2. Reconstruir passa pelas regras da classe #

Um documento pode estar sintaticamente correto e ainda conter um preço negativo ou um nome vazio. A leitura JSON responde se o texto pode ser interpretado; a construção do objeto verifica regras do domínio. Campos ausentes também precisam de um tratamento definido.

Nos exemplos, validamos o tipo do registro, exigimos campos nome e preco_centavos e usamos o construtor para validar os valores. Campos adicionais não são usados pelo adaptador. Em aplicações maiores, a decisão de aceitar ou rejeitar campos extras deve ser documentada.

3. Arquivo é uma fronteira separada #

Para gravar em disco, use um caminho de saída explícito e não substitua a base original durante uma experiência. Primeiro teste a conversão em memória. Depois conecte leitura e escrita com encoding UTF-8 e tratamento apropriado de falhas.

Os exemplos deste pacote usam apenas texto JSON em memória para serem executáveis sem arquivos externos. O exercício de arquivo pede um destino de saída próprio. Isso mantém separados o comportamento de Produto e os detalhes de persistência.

4. Um exemplo acompanhado

O programa abaixo é completo e independente. Antes de executar, procure o estado inicial e a operação que produz o resultado. Os comentários documentam as responsabilidades.

Python
import json


class Produto:
    """Representa um nome válido e preço em centavos."""

    def __init__(self, nome, preco_centavos):
        """Valida o estado reconstruído ou criado manualmente."""
        if not isinstance(nome, str) or not nome.strip():
            raise ValueError("Nome inválido")
        if type(preco_centavos) is not int or preco_centavos < 0:
            raise ValueError("Preço inválido")
        self.nome = nome
        self.preco_centavos = preco_centavos


def para_registro(produto):
    """Converte o domínio para campos simples de JSON."""
    return {"nome": produto.nome, "preco_centavos": produto.preco_centavos}


def do_registro(registro):
    """Exige campos mínimos; valores passam pelo construtor."""
    if not isinstance(registro, dict) or not {"nome", "preco_centavos"} <= registro.keys():
        raise ValueError("Registro incompleto")
    return Produto(registro["nome"], registro["preco_centavos"])

p = Produto("Creme", 1200)
print(json.dumps(para_registro(p), ensure_ascii=False))
Saída
{"nome": "Creme", "preco_centavos": 1200}
