# POO — Lojas Blue

12 tópicos, 36 exemplos independentes e 72 exercícios sem solução. Use Python 3.10 ou superior, UTF-8 e nenhuma biblioteca externa. Comece por ORDEM_DE_ESTUDO.md.

Cada pasta tem exemplos/ e exercicios/. Execute um exemplo por vez: `python 01_do_registro_ao_objeto/exemplos/01_retirada_valida.py`. No Windows, pode usar `py -3`. Exemplos não solicitam entrada, não alteram arquivos e usam dados sintéticos. Exercícios são apenas comentários até você implementar sua solução.

Valores monetários desta trilha usam centavos inteiros; não há conversão automática da base de PED. A forma procedural do primeiro tópico é intencional: ela prepara a passagem para classes. Não execute scripts desconhecidos sem leitura prévia.
