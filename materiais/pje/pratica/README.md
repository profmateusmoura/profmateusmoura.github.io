# PJE — pacote de prática
Referência: Godot 4.5.1 Standard / Compatibility e GDScript. Extraia o ZIP antes de abrir.
1. Leia os cadernos pelo portal. As fontes em Markdown estão em cadernos/ neste pacote.
2. Pesquisa e design: use 01_pesquisa_e_design.
3. Microjogo: importe um project.godot de 02_microjogo/etapa_01 até etapa_04.
4. Plataforma: importe um project.godot de 03_plataforma/etapa_01 até etapa_05.
5. Em cada versão leia LEIA-ME.md e compare ETAPA no Main.gd. São versões cumulativas.
6. Exercícios por caderno ficam em exercicios/. Arquivos .gd com enunciados são fichas, não scripts prontos para anexar.
7. Planejamento, teste e entrega do projeto autoral ficam em 04_projeto_etmsl.
8. Guia docente: GUIA_DOCENTE.md. Tutoriais usam teclado e mouse no computador.
Os jogos-fonte não são exportações web. O caderno final explica como exportar e conferir.
