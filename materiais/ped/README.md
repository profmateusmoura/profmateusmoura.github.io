# PED — Programação e Estruturas de Dados

Site educacional independente, incorporado ao Portal de Estudos.

- Abra `index.html` para acessar os seis cadernos.
- Os arquivos em `cadernos/` contêm as lições com exemplos Python.
- Os PDFs de cada caderno estão em `arquivos/`.
- `assets/` contém o CSS, o JavaScript e o índice de pesquisa.
- Os links de retorno ao portal são relativos e funcionam tanto em páginas de usuário como de projeto.

Para publicar: mantenha a pasta inteira em `materiais/ped/`.
