# Prática de Estruturas de Dados em Python

24 temas, 24 exemplos executáveis e 48 exercícios. Use Python 3, sem instalar pacotes.

Extraia o ZIP antes de abrir os arquivos. Em cada pasta, leia exemplo.py, depois complete exercicio_01.py e exercicio_02.py. Os enunciados estão na documentação inicial de cada arquivo. Execute pelo editor ou no terminal com `python exemplo.py`. Os arquivos de exercícios são pontos de partida: não imprimem respostas prontas.

Os dados são didáticos e autocontidos. Não dependem do JSON da disciplina. As saídas esperadas orientam a conferência; os exemplos apresentam soluções de problemas semelhantes.

## Percurso

- 01_listas_atualizacao: Alterar sem aumentar
- 02_listas_percurso: A variável muda, a saída cresce
- 03_listas_fatias: O fim fica de fora
- 04_tuplas: Desempacote uma tupla
- 05_dicionarios: Atualizar por chave
- 06_conjuntos: Interseção entre lojas
- 07_registros: Filtre registros completos
- 08_copia_profunda: Uma cópia de dados aninhados
- 09_json: Texto JSON vira objeto Python
- 10_busca_linear: Uma comparação por vez
- 11_busca_binaria: Reduza o intervalo
- 12_bubble_sort: Trocas entre vizinhos
- 13_selection_sort: Escolha o menor restante
- 14_insertion_sort: Abra espaço e insira
- 15_merge_sort: Divida e intercale
- 16_quick_sort: Particione em torno do pivô
- 17_pilhas: Desfaça a última ação
- 18_filas: Atenda por ordem de chegada
- 19_encadeadas: Siga a próxima referência
- 20_hash: Duas chaves no mesmo balde
- 21_complexidade: Conte operações, não segundos
- 22_recursao: Empilhe chamadas e retorne
- 23_arvores: Escolha um ramo da árvore
- 24_grafos: Busca em largura com fila
