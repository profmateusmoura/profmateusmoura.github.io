# Uso em aula

Para cada tema: peça uma previsão individual (2 min), percorra a simulação com a turma (5 min), execute o exemplo (5 min) e proponha o exercício 1 em duplas (10–15 min). Use o exercício 2 como investigação ou tarefa.

Avalie a explicação, o resultado e a preservação das propriedades da estrutura. As simulações mostram sequências didáticas predeterminadas; não executam Python no navegador. O botão de voltar permite revisar estados, não representa uma instrução Python.

## Saídas dos exemplos

```text
['Shampoo', 'Sabonete', 'Creme']
3
```
