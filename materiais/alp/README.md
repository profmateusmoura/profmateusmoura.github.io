# ALP — Cadernos de estudo

13 cadernos explicativos em sequência didática: conceitos, analogias, pequenos códigos com saída explicada, demonstração guiada, síntese e critérios de autonomia. Os 117 exemplos completos e 301 exercícios estão nos ZIPs e no diretório pratica/. A busca aponta para as explicações, não para um catálogo de arquivos.

Os exemplos com input têm roteiros de execução; não são executados no navegador.
