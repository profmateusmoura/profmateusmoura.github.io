Como estudar este caderno

Leia as seções na ordem. Cada uma desenvolve uma ideia, mostra como ela aparece no código e explica o resultado. Os códigos curtos do texto são exemplos de leitura; o pacote ZIP reúne os programas completos e os exercícios para praticar depois.

Antes de executar um código, preveja o que será exibido. Compare a previsão com a explicação e observe qual instrução produz cada mudança. Não é necessário acertar de primeira: localizar a diferença faz parte do estudo.

No mundo físico

Use uma tabela de nomes e valores no papel. Risque apenas o valor que foi substituído. A tabela é uma representação didática do estado, não um desenho literal da memória.

1. Atribuir é dar um nome a um valor

Para reutilizar uma informação, associamos um nome a um valor. Em estoque = 18, o lado direito é avaliado e seu valor é associado ao nome estoque. O sinal = representa atribuição. Uma nova atribuição ao mesmo nome substitui sua associação anterior; ela não altera automaticamente outros nomes que receberam o valor antes.

2. Atribuição é uma fotografia do valor daquele momento

Uma maneira de acompanhar atribuições é escrever uma tabela no papel, com uma coluna por variável. Depois de cada instrução, atualize apenas a coluna correspondente ao lado esquerdo. Os nomes não são caixas físicas, mas essa representação ajuda a registrar o estado do programa.

Quando uma variável recebe o valor de outra, o valor usado é o daquele instante. Se uma atribuição posterior trocar o valor associado ao primeiro nome, o segundo não será recalculado automaticamente. A expressão de uma atribuição não fica funcionando como uma fórmula de planilha. Ela é avaliada quando a linha executa.

Python · exemplo explicado
nome = "Shampoo"
anterior = nome
nome = "Batom"
print(anterior)
print(nome)
Resultado
Shampoo
Batom

Como ler a execução

anterior recebe "Shampoo" antes da mudança. A nova atribuição altera nome, mas não executa novamente a linha anterior = nome.

3. O tipo determina o significado da informação

int representa inteiros; float representa números com parte fracionária; str representa texto; bool representa True ou False. O texto "18" e o inteiro 18 parecem iguais ao serem exibidos, mas têm tipos diferentes. input sempre fornece texto. int e float fazem conversões quando esse texto tem um formato aceito. Neste tópico, use entradas válidas; o tratamento de erros será estudado posteriormente.

4. Transformar uma entrada textual em um número

Para guardar uma resposta, atribua o resultado de input a um nome. Para interpretar essa resposta como um inteiro, use int; para um decimal, use float. É útil enxergar duas etapas distintas, mesmo quando aparecem em uma única expressão: receber caracteres e convertê-los.

A conversão não aceita qualquer texto. int("18") funciona, enquanto int("dezoito") não representa um formato inteiro válido. Neste ponto da trilha, use os formatos previstos pelo exemplo. O tratamento de ValueError será apresentado no caderno de validação; não é preciso esconder esse pré-requisito nem antecipar seu código agora.

Python · exemplo explicado
texto = "18"
quantidade = int(texto)
print(type(texto).__name__)
print(type(quantidade).__name__)
Resultado
str
int

Como ler a execução

Os caracteres originais continuam associados a texto. A variável quantidade recebe outro valor, de tipo inteiro. A conversão não altera a string original.

5. Valor armazenado e apresentação são diferentes

Uma formatação como :.2f controla quantas casas decimais aparecem na saída. Ela não transforma a variável original em uma quantidade monetária exata. Use ponto para digitar números decimais em float. Escolha nomes que expliquem o papel de cada informação e acompanhe as atribuições em um rascunho antes de executar. Os cálculos e comparações entram no próximo caderno.

6. Apresentação com duas casas não altera o valor

Em mensagens de preço, é comum exibir duas casas decimais. A formatação descreve como o valor deve aparecer para o leitor. Não confunda essa escolha visual com a representação interna de float: alguns números decimais não têm representação binária exata. Neste curso, os valores são didáticos; situações financeiras reais podem exigir outra representação e outras regras.

Na f-string, o prefixo f permite colocar uma expressão entre chaves. O trecho :.2f pede duas casas na apresentação. A palavra e o símbolo de moeda fora das chaves são texto. Após imprimir, a variável continua com seu valor numérico e pode ser utilizada nas próximas etapas.

Python · exemplo explicado
preco = 24.9
print(f"Preço: R$ {preco:.2f}")
print(preco)
Resultado
Preço: R$ 24.90
24.9

Como ler a execução

A primeira linha formata a apresentação. A segunda mostra a representação padrão do mesmo valor; isso confirma que a variável não se tornou o texto "24.90".
