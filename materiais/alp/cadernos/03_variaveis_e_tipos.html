1. Guardar valores com atribuição (=) #

Uma variável associa um nome legível (identificador) a um valor guardado na memória. Em Python, criamos uma variável no momento em que fazemos uma atribuição com o sinal =.

O sinal = na programação não representa uma pergunta de igualdade matemática: ele é uma ordem de armazenamento. O Python primeiro resolve o que está à direita do = e, em seguida, guarda o valor resultante no nome escrito à esquerda. Bons nomes usam letras minúsculas e sublinhados (snake_case), como nome_produto ou estoque_atual.

Python
filial = "Belo Horizonte"
setor = "Perfumaria"
caixa_ativo = 3

print("Filial:", filial)
print("Setor:", setor)
print("Caixa:", caixa_ativo)

Saída: Filial: Belo Horizonte / Setor: Perfumaria / Caixa: 3

Linha executadaEstado de filialEstado de setorEstado de caixa_ativo
1. filial = "Belo Horizonte""Belo Horizonte"(ainda não existe)(ainda não existe)
2. setor = "Perfumaria""Belo Horizonte""Perfumaria"(ainda não existe)
3. caixa_ativo = 3"Belo Horizonte""Perfumaria"3
NO MUNDO FÍSICO

Imagine caixas identificadas com etiquetas adesivas ('filial', 'setor', 'caixa_ativo') no balcão da loja. Quando consultamos print(filial), olhamos o valor guardado sob aquela etiqueta sem apagá-lo.

2. Reatribuição e evolução do estado #

Uma variável escalar guarda apenas um valor por vez. Quando atribuímos um novo valor a um nome que já existia, o valor anterior é substituído a partir daquela linha.

Além disso, quando fazemos copia = estoque, a variável copia recebe o valor que estoque possui naquele exato instante. Se estoque mudar nas linhas seguintes, copia continuará com o valor antigo, pois não fica 'amarrada' automaticamente a futuras mudanças.

Python
estoque = 15
print("Estoque na abertura:", estoque)

copia_abertura = estoque
estoque = 12
print("Estoque após vendas:", estoque)
print("Registro da abertura:", copia_abertura)

Saída: Estoque na abertura: 15 / Estoque após vendas: 12 / Registro da abertura: 15

PassoInstruçãoValor de estoqueValor de copia_abertura
1estoque = 1515—
2copia_abertura = estoque1515 (recebeu o valor atual de estoque)
3estoque = 1212 (substituído)15 (permanece inalterado)

3. Os quatro tipos escalares: int, float, str e bool #

Todo valor em Python possui um tipo, que define como ele é representado na memória e quais operações são permitidas com ele. Em Algoritmos e Lógica de Programação, trabalhamos com quatro tipos escalares fundamentais:

• int: números inteiros positivos, negativos ou zero (ex.: 18, 0, -4).

• float: números reais com ponto decimal (ex.: 24.90, 0.5, 10.0).

• str: textos delimitados por aspas (ex.: "Shampoo", "18").

• bool: valores lógicos de verdade, restritos a exatamente dois literais: True ou False (com inicial maiúscula).

Python
unidades = 18
preco_unitario = 24.90
nome_item = "Shampoo Neutro"
em_promocao = True

print(unidades, type(unidades))
print(preco_unitario, type(preco_unitario))
print(nome_item, type(nome_item))
print(em_promocao, type(em_promocao))

Saída: 18 <class 'int'> / 24.9 <class 'float'> / Shampoo Neutro <class 'str'> / True <class 'bool'>

Tipo em PythonSignificadoExemplos válidosCuidado na escrita
intNúmero inteiro0, 15, -3, 1200Escrito sem aspas e sem parte decimal.
floatNúmero real (ponto flutuante)19.90, 0.0, 3.14Usa sempre ponto (.) como separador decimal, nunca vírgula.
strTexto (cadeia de caracteres)"Creme", "15", ""Delimitado por aspas; '15' com aspas é texto, não número.
boolValor lógico (booleano)True, FalseInicial obrigatoriamente maiúscula e sem aspas.
ATENÇÃO

Em Python, escrever preco = 24,90 com vírgula não cria um número float! O separador decimal no código-fonte é sempre o ponto: preco = 24.90.

4. Guardando leituras de input() em variáveis #

Agora podemos combinar input() com atribuição: resposta = input("..."). Em vez de perder o valor lido imediatamente, guardamos o texto digitado na variável resposta e podemos reutilizá-lo quantas vezes quisermos.

Lembre-se da regra de ouro: toda chamada de input() devolve um valor do tipo str, mesmo quando o operador digita apenas algarismos.

Python
produto = input("Nome do produto: ")
codigo_texto = input("Código da etiqueta: ")

print("Etiqueta gerada para:", produto)
print("Código lido:", codigo_texto, "Tipo:", type(codigo_texto))

Saída: Nome do produto: [Protetor Solar] / Código da etiqueta: [402] / Etiqueta gerada para: Protetor Solar / Código lido: 402 Tipo: <class 'str'>

VariávelOrigem do valorValor armazenadoTipo observado com type()
produtoinput("Nome do produto: ")"Protetor Solar"str
codigo_textoinput("Código da etiqueta: ")"402"str (ainda é texto!)

5. Conversão explícita de tipos: int(), float() e str() #

Quando precisamos representar uma quantidade inteira ou um preço numérico a partir de uma leitura do teclado, convertemos explicitamente o texto usando int(...) ou float(...). Da mesma forma, str(...) converte números ou booleanos em texto.

Podemos fazer a conversão em duas etapas (lendo primeiro para uma variável de texto e convertendo depois) ou diretamente na mesma linha: quantidade = int(input("Quantidade: ")).

Python
texto_qtd = input("Quantidade recebida: ")
quantidade = int(texto_qtd)
preco = float(input("Preço unitário (use ponto): "))

print("Quantidade:", quantidade, type(quantidade))
print("Preço:", preco, type(preco))

Saída: Quantidade recebida: [4] / Preço unitário (use ponto): [18.50] / Quantidade: 4 <class 'int'> / Preço: 18.5 <class 'float'>

Função de conversãoExemplo de entrada compatívelResultado devolvidoEntrada incompatível (gera ValueError)
int(x)"42", "-7", 19.942, -7, 19 (trunca decimais de float)"19.9" (string com ponto) ou "doze"
float(x)"18.50", "42", 1018.5, 42.0, 10.0"18,50" (com vírgula) ou "caro"
str(x)42, 18.5, True"42", "18.5", "True"(Qualquer valor básico pode virar str)

6. Exibição organizada com múltiplos argumentos e f-strings #

Para apresentar fichas e relatórios combinando textos e variáveis, podemos tanto passar as variáveis separadas por vírgula no print() quanto utilizar f-strings (strings formatadas precedidas pela letra f antes das aspas).

Em uma f-string, qualquer variável colocada entre chaves {nome_variavel} é avaliada e inserida diretamente naquela posição da frase. Para valores float como preços monetários, o especificador {preco:.2f} exibe o número sempre com duas casas decimais.

Python
produto = "Creme Hidratante"
estoque = 25
preco = 29.9

print("Item:", produto, "| Estoque:", estoque)
print(f"Ficha Lojas Blue -> {produto}: {estoque} un. por R$ {preco:.2f}")

Saída: Item: Creme Hidratante | Estoque: 25 / Ficha Lojas Blue -> Creme Hidratante: 25 un. por R$ 29.90

DICA PRÁTICA

A formatação {preco:.2f} mostra 29.9 como 29.90 na tela sem alterar o número guardado na variável preco.
