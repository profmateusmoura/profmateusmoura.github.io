Entenda a ideia

Transformar uma tarefa grande em responsabilidades

Um orçamento pode envolver leitura, validação, cálculo e apresentação. Escrever tudo em um bloco dificulta verificar cada parte. Decomponha o problema descrevendo tarefas pequenas e seus contratos. A função de cálculo não precisa perguntar dados ao usuário; ela recebe valores já aceitos. A função de apresentação não precisa repetir a fórmula.

Planejar o caminho dos dados

Desenhe quem chama quem e qual valor cada função devolve. Uma função principal pode coordenar as etapas: obter valores, chamar cálculos e mostrar o resultado. Se uma função precisa de um dado, prefira passá-lo por parâmetro em vez de depender silenciosamente de uma variável externa. Essa relação explícita permite testar uma parte com valores fixos.

Integrar depois de conferir as partes

Primeiro teste funções pequenas em casos comuns e de fronteira. Depois execute a sequência completa, verificando se a saída de uma etapa atende à entrada da próxima. Não basta cada função funcionar isoladamente se elas discordam sobre unidades ou domínio. Nos projetos do caderno, os leitores e os contratos devem ser respeitados; erros de entrada são tratados na etapa de leitura, antes do cálculo.

Erros para observar

Fragmentar cada linha em uma função sem propósito; fazer toda a lógica em main; manter estado global oculto; retornar vários dados por tupla. Neste curso, cada retorno é escalar, e o estado conjunto pode permanecer no coordenador.

# 01 — Decompor um orçamento
# Objetivo: Transformar entrada, cálculo e saída em etapas nomeadas.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: O fluxo fica em main; cada função tem uma responsabilidade.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   8.5
#   3
# Confira na saída: 'Total do orçamento: R$ 25.50'

# Plano: ler preço -> ler quantidade -> calcular -> mostrar.
def ler_preco():
    """Leia e retorne um preço não negativo, recusando formato inválido."""
    while True:
        try:
            preco = float(input("Preço (ponto decimal): "))
        except ValueError:
            print("Digite um número.")
            continue
        # Também recusa NaN e infinito, que float aceita como texto.
        if 0 <= preco < float("inf"):
            return preco
        print("Informe um preço finito não negativo.")

def ler_quantidade():
    """Leia e retorne uma quantidade inteira positiva."""
    while True:
        try:
            quantidade = int(input("Quantidade: "))
        except ValueError:
            print("Digite um inteiro.")
            continue
        if quantidade > 0:
            return quantidade
        print("Use quantidade positiva.")

def calcular_total(preco, quantidade):
    """Retorne o total para preço não negativo e quantidade positiva."""
    return preco * quantidade

def mostrar_total(total):
    """Exiba total numérico com duas casas decimais."""
    print(f"Total do orçamento: R$ {total:.2f}")

def main():
    """Coordene a leitura, o cálculo e a apresentação do orçamento."""
    preco = ler_preco()
    quantidade = ler_quantidade()
    total = calcular_total(preco, quantidade)
    mostrar_total(total)

# Esta condição chama main quando o arquivo é executado diretamente.
# Ao importar o arquivo, as funções ficam disponíveis sem abrir a interação.
if __name__ == "__main__":
    main()
02 — Boletim de duas notasBaixar este exemplo .py
# 02 — Boletim de duas notas
# Objetivo: Reutilizar uma leitura e manter o cálculo independente.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: Duas chamadas da mesma função evitam duplicar a validação.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   6
#   8
# Confira na saída: 'Situação: Aprovado'

# Plano: duas leituras válidas -> média -> classificação -> saída.
def ler_nota(mensagem):
    """Leia e retorne uma nota numérica de 0 a 10 inclusive."""
    while True:
        try:
            nota = float(input(mensagem))
        except ValueError:
            print("Formato inválido.")
            continue
        if 0 <= nota <= 10:
            return nota
        print("Nota fora da faixa.")

def calcular_media(nota_1, nota_2):
    """Retorne a média aritmética de duas notas válidas."""
    return (nota_1 + nota_2) / 2

def classificar(media):
    """Retorne a situação para média válida; cortes em 5 e 7."""
    if media >= 7:
        return "Aprovado"
    if media >= 5:
        return "Recuperação"
    return "Reprovado"

def main():
    """Coordene o boletim sem guardar notas em coleções."""
    nota_1 = ler_nota("Nota 1: ")
    nota_2 = ler_nota("Nota 2: ")
    media = calcular_media(nota_1, nota_2)
    print(f"Média: {media:.1f}")
    print("Situação:", classificar(media))

if __name__ == "__main__":
    main()

# Objetivo: Combinar validação reutilizável e função de decisão.

def ler_positivo(mensagem):
    """Leia e retorne um inteiro estritamente positivo."""
    while True:
        try:
            numero = int(input(mensagem))
        except ValueError:
            print("Use um inteiro.")
            continue
        if numero > 0:
            return numero
        print("Use um valor positivo.")

def eh_divisivel(numero, divisor):
    """Retorne se divisor divide numero; ambos devem ser positivos."""

    """Apresente o teste entre dois positivos e um resultado bool."""
    if divisivel:
        print(f"{numero} é divisível por {divisor}.")

        print(f"{numero} não é divisível por {divisor}.")

    """Integre as etapas do teste de divisibilidade."""
    numero = ler_positivo("Número: ")
    divisor = ler_positivo("Divisor: ")
    resposta = eh_divisivel(numero, divisor)
    mostrar_resultado(numero, divisor, resposta)

    main()

# 04 — Resumo de uma turma sem histórico
# Objetivo: Decompor um processamento de várias entradas.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: O processamento retorna só a média; notas são consumidas uma por vez.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   3
#   7
#   8
#   9
# Confira na saída: 'Média da turma: 8.00'

def ler_quantidade():
    """Leia e retorne o tamanho positivo da turma como inteiro."""
    while True:
        try:
            quantidade = int(input("Quantidade de estudantes: "))
        except ValueError:
            print("Use um inteiro.")
            continue
        if quantidade > 0:
            return quantidade
        print("A turma deve ter ao menos um estudante.")

def ler_nota():
    """Leia e retorne uma nota de 0 a 10 inclusive."""
    while True:
        try:
            nota = float(input("Nota: "))
        except ValueError:
            print("Use um número.")
            continue
        if 0 <= nota <= 10:
            return nota
        print("Nota inválida.")

def processar_turma(quantidade):
    """Leia quantidade notas válidas e retorne a média; quantidade > 0.

    Esta função coordena leituras e acumulação; não preserva as notas.
    """
    soma = 0.0
    for ordem in range(1, quantidade + 1):
        print("Estudante", ordem)
        soma += ler_nota()
    return soma / quantidade

def main():
    """Leia o tamanho da turma, processe as notas e exiba a média."""
    quantidade = ler_quantidade()
    media = processar_turma(quantidade)
    print(f"Média da turma: {media:.2f}")

if __name__ == "__main__":
    main()
05 — Menu de ferramentas numéricasBaixar este exemplo .py
# 05 — Menu de ferramentas numéricas
# Objetivo: Separar controle do menu e algoritmos puros.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: Cada opção pede só um inteiro não negativo e retorna um escalar.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   1
#   0
#   2
#   204
#   0
# Confira na saída: 'Soma: 6'

def ler_nao_negativo():
    """Leia e retorne um inteiro maior ou igual a zero."""
    while True:
        try:
            numero = int(input("Inteiro não negativo: "))
        except ValueError:
            print("Formato inválido.")
            continue
        if numero >= 0:
            return numero
        print("Não use negativos.")

def calcular_fatorial(numero):
    """Retorne o fatorial do inteiro não negativo numero."""
    produto = 1
    for fator in range(2, numero + 1):
        produto *= fator
    return produto

def somar_algarismos(numero):
    """Retorne a soma dos algarismos do inteiro não negativo numero."""
    soma = 0
    while numero > 0:
        soma += numero % 10
        numero //= 10
    return soma

def main():
    """Mantenha o menu ativo até o usuário escolher zero."""
    while True:
        print("1: fatorial | 2: soma de algarismos | 0: sair")
        opcao = input("Opção: ")
        match opcao:
            case "1":
                numero = ler_nao_negativo()
                print("Fatorial:", calcular_fatorial(numero))
            case "2":
                numero = ler_nao_negativo()
                print("Soma:", somar_algarismos(numero))
            case "0":
                break
            case _:
                print("Opção inválida.")
    print("Programa encerrado")

if __name__ == "__main__":
    main()

# 06 — Projeto integrador: sessão de exercícios
# Objetivo: Integrar menu, validação, contagem, média e funções.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: O estado da sessão permanece em main; cada função recebe o necessário.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   2
#   1
#   8
#   1

#   0
# Confira na saída: 'Média: 7.00'

# Requisitos: registrar pontuação de 0 a 10, consultar resumo e sair.
# Sem arquivos ou histórico: só quantidade, soma e maior pontuação.
def ler_pontuacao():
    """Leia e retorne uma pontuação numérica válida de 0 a 10."""
    while True:
        try:
            valor = float(input("Pontuação de 0 a 10: "))
        except ValueError:
            print("Use um número.")
            continue
        if 0 <= valor <= 10:
            return valor
        print("Pontuação fora da faixa.")

def calcular_media(soma, quantidade):
    """Retorne soma / quantidade; quantidade deve ser positiva."""
    return soma / quantidade

def mostrar_resumo(quantidade, soma, maior):
    """Exiba os totais; maior só é significativo quando quantidade > 0."""
    if quantidade == 0:
        print("Nenhum exercício registrado.")
        return  # Retorno sem valor: encerra a apresentação deste caso.
    print("Exercícios registrados:", quantidade)
    print(f"Média: {calcular_media(soma, quantidade):.2f}")
    print(f"Maior pontuação: {maior:.2f}")

def main():
    """Controle o estado e coordene os serviços da sessão."""
    quantidade = 0
    soma = 0.0
    maior = 0.0  # Só será consultado depois do primeiro registro.
    while True:
        print("1: registrar | 2: resumo | 0: encerrar")
        opcao = input("Opção: ")
        match opcao:
            case "1":
                valor = ler_pontuacao()
                if quantidade == 0 or valor > maior:
                    maior = valor
                soma += valor
                quantidade += 1
            case "2":
                mostrar_resumo(quantidade, soma, maior)
            case "0":
                mostrar_resumo(quantidade, soma, maior)
                break
            case _:
                print("Opção inválida.")

if __name__ == "__main__":
    main()

# Serviço escalar de reposição — cenário didático Lojas Blue
# Objetivo: Separar leitura validada, cálculo e apresentação.
# Pré-requisito: tópicos anteriores e exemplos anteriores deste tópico.

#   4

def ler_nao_negativo(mensagem):
    """Leia e retorne um inteiro não negativo, repetindo entradas inválidas."""
    while True:
        try:
            valor = int(input(mensagem))
        except ValueError:
            print("Digite um inteiro.")
            continue
        if valor >= 0:

        print("Não use negativos.")

def sugerir(saldo, minimo):
    """Retorne a falta até o mínimo para inteiros não negativos."""
    if saldo < minimo:
        return minimo - saldo
    return 0

def main():
    """Coordene a conferência de uma posição de estoque por execução."""
    saldo = ler_nao_negativo("Saldo: ")
    minimo = ler_nao_negativo("Mínimo: ")
    print("Reposição sugerida:", sugerir(saldo, minimo))

if __name__ == "__main__":
    main()

# Reposição: quatro posições, uma por vez
# Estude os exemplos anteriores deste tópico antes desta aplicação.
# Execução: python 12_decomposicao_de_problemas/exemplos/91_caso_reposicao.py
# Confira na saída: 'Depois da retirada: 4 críticas e 10 a repor'
# Preveja o resultado e altere um dado por vez para conferir seu raciocínio.

def calcular_falta(saldo, minimo):
    """Retorne a falta até o mínimo para inteiros não negativos."""
    if saldo < minimo:
        return minimo - saldo
    return 0

def main():
    """Resuma quatro posições com variáveis escalares, sem guardar coleção."""
    criticas = 0
    total = 0
    # Unidade 1, produto 1: saldo 18 e mínimo 10.
    falta = calcular_falta(18, 10)
    if falta > 0:
        criticas += 1
    total += falta
    # Unidade 1, produto 4: saldo 4 e mínimo 8.
    falta = calcular_falta(4, 8)
    if falta > 0:
        criticas += 1
    total += falta
    # Unidade 1, produto 10: saldo 6 e mínimo 10.
    falta = calcular_falta(6, 10)
    if falta > 0:
        criticas += 1
    total += falta
    # Unidade 3, produto 2: saldo 9 e mínimo 10.
    falta = calcular_falta(9, 10)
    if falta > 0:
        criticas += 1
    total += falta
    print("Posições críticas:", criticas)
    print("Total a repor:", total)
    # Simule retirar nove da primeira posição: só a sua falta precisa mudar.
    adicional = calcular_falta(18 - 9, 10)
    print("Depois da retirada:", criticas + 1, "críticas e", total + adicional, "a repor")

if __name__ == "__main__":
    main()
