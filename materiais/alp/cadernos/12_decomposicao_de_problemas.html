1. Por que dividir um problema grande em subproblemas #

Um programa bem estruturado separa claramente três naturezas de trabalho:

1. Entrada e validação: interagir com o teclado e devolver um dado limpo.

2. Processamento (regras de negócio): receber números por parâmetro, aplicar as fórmulas/decisões e retornar o resultado.

3. Saída (apresentação): receber os resultados prontos e formatar o comprovante na tela.

Quando separamos essas três camadas, podemos testar cada regra de cálculo diretamente (passando números fixos) sem precisar digitar dados no teclado a cada teste!

Python
def calcular_bruto(quantidade, preco_unitario):
    return quantidade * preco_unitario

def aplicar_cupom(valor_bruto, desconto_fixo):
    if valor_bruto >= desconto_fixo:
        return valor_bruto - desconto_fixo
    return 0.0

def exibir_resumo(bruto, liquido):
    print(f"Bruto: R$ {bruto:.2f} | Total a pagar: R$ {liquido:.2f}")

bruto = calcular_bruto(4, 25.0)
liquido = aplicar_cupom(bruto, 10.0)
exibir_resumo(bruto, liquido)

Saída: Bruto: R$ 100.00 | Total a pagar: R$ 90.00

2. Planejamento Top-Down e contratos de função #

No planejamento Top-Down (de cima para baixo), começamos desenhando o resumo geral do programa antes de nos preocuparmos com os detalhes de cada conta. Para cada etapa, escrevemos o contrato da função: qual é o seu nome, o que ela espera receber e o que ela promete devolver.

Uma função auxiliar pode chamar outra função auxiliar. Por exemplo, calcular_total_final(qtd, preco, regiao) pode chamar internamente calcular_subtotal(qtd, preco) e calcular_frete(regiao).

Python
def calcular_subtotal(qtd, preco):
    return qtd * preco

def calcular_frete(subtotal):
    if subtotal >= 150.0:
        return 0.0
    return 18.0

def calcular_total_pedido(qtd, preco):
    sub = calcular_subtotal(qtd, preco)
    frete = calcular_frete(sub)
    return sub + frete

print("Pedido 1 (2 x R$ 40):", calcular_total_pedido(2, 40.0))
print("Pedido 2 (4 x R$ 50):", calcular_total_pedido(4, 50.0))

Saída: Pedido 1 (2 x R$ 40): 98.0 / Pedido 2 (4 x R$ 50): 200.0

3. Reaproveitando funções de leitura e validação #

Se um programa precisa ler três números inteiros positivos (quantidade no depósito, quantidade na vitrine e estoque mínimo), não precisamos escrever três laços while de validação repetidos.

Basta criar uma única função ler_inteiro_positivo(mensagem) que recebe o prompt como parâmetro, valida o dado e retorna o inteiro pronto.

Python
def validar_estoque_nao_negativo(valor_lido):
    if valor_lido < 0:
        return 0
    return valor_lido

deposito = validar_estoque_nao_negativo(30)
vitrine = validar_estoque_nao_negativo(-4)
print("Total disponível:", deposito + vitrine)

Saída: Total disponível: 30

4. A função coordenadora main() #

Para que nenhuma variável fique solta no escopo global do arquivo, reunimos o fluxo principal do programa dentro de uma função chamada main(). Ao ler main(), qualquer pessoa entende imediatamente a história completa do programa em poucas linhas.

No final do arquivo, usamos a verificação padrão if __name__ == "__main__": main() para iniciar o programa.

Python
def registrar_entrada(saldo, quantidade):
    return saldo + quantidade

def registrar_saida(saldo, quantidade):
    if quantidade <= saldo:
        return saldo - quantidade
    print("Aviso: saldo insuficiente para retirada!")
    return saldo

def main():
    saldo_estoque = 50
    saldo_estoque = registrar_entrada(saldo_estoque, 20)
    saldo_estoque = registrar_saida(saldo_estoque, 15)
    print("Saldo final consolidado:", saldo_estoque)

if __name__ == "__main__":
    main()

Saída: Saldo final consolidado: 55

5. Integrando laços e funções em relatórios de lote #

Quando precisamos processar N vendas seguidas, o laço fica em main() (ou em uma função coordenadora de lote) e chama a função auxiliar de cálculo a cada repetição para obter o valor líquido de cada item e somá-lo ao faturamento total.

Python
def liquido_item(bruto):
    if bruto >= 100.0:
        return bruto * 0.90
    return bruto

def fechar_lote():
    faturamento = 0.0
    for venda in range(1, 4):
        valor_bruto = venda * 50.0  # 50.0, 100.0, 150.0
        faturamento = faturamento + liquido_item(valor_bruto)
    return faturamento

print(f"Faturamento líquido do lote: R$ {fechar_lote():.2f}")

Saída: Faturamento líquido do lote: R$ 275.00

6. Sinais de uma boa decomposição #

Antes de dar um programa por concluído, verifique quatro critérios de qualidade:

1. Alguma função está fazendo coisas demais (lendo, calculando e imprimindo tudo misturado)?

2. Todas as informações necessárias entram pelos parâmetros e saem pelo return?

3. Os nomes das funções começam com verbos claros (calcular_frete, validar_nota, exibir_cupom)?

4. É possível explicar o que cada função faz em uma única frase curta?

Python
def classificar_meta(total_vendido, meta_mensal):
    if total_vendido >= meta_mensal:
        return "Meta atingida"
    return "Abaixo da meta"

print("Status da filial:", classificar_meta(18500.0, 15000.0))

Saída: Status da filial: Meta atingida
