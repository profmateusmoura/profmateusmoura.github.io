1. Validação de faixa e opções com while #

Para impedir que uma nota fora da faixa de 0 a 10 ou uma quantidade menor ou igual a zero avance para os cálculos da loja, colocamos um laço while logo após a leitura.

A condição do while de validação deve descrever quando o dado é INVÁLIDO (para continuar pedindo). Assim, se o intervalo válido é de 0 até 10 (nota >= 0 and nota <= 10), a condição de repetição do while é a negação: while nota < 0 or nota > 10:.

Python
# Simulando tentativas: -2 (inválida), 14 (inválida) e 8 (válida)
tentativa = 1
nota = -2

while nota < 0 or nota > 10:
    print(f"Nota {nota} inválida! Digite um valor entre 0 e 10.")
    tentativa = tentativa + 1
    if tentativa == 2:
        nota = 14
    else:
        nota = 8

print("Nota validada com sucesso:", nota)

Saída: Nota -2 inválida! Digite um valor entre 0 e 10. / Nota 14 inválida! Digite um valor entre 0 e 10. / Nota validada com sucesso: 8

Regra para o dado ser VÁLIDOCondição do while para REJEITAR e pedir de novo
Quantidade positiva: qtd > 0while qtd <= 0:
Nota de 0 a 10: nota >= 0 and nota <= 10while nota < 0 or nota > 10:
Opção 1 ou 2: opcao == 1 or opcao == 2while opcao != 1 and opcao != 2:

2. Protegendo conversões com try / except ValueError #

O laço while qtd <= 0: funciona quando o usuário digita um número inteiro como -5. Mas se ele digitar a palavra "dez" ou pressionar Enter vazio, a chamada int(input(...)) levantará uma exceção ValueError e interromperá o programa imediatamente.

Para capturar essa falha com elegância, colocamos a tentativa de conversão dentro do bloco try: e tratamos o erro no bloco except ValueError:.

Python
entrada_bruta = "abc"

try:
    quantidade = int(entrada_bruta)
    print("Quantidade convertida:", quantidade)
except ValueError:
    print("Erro: digite apenas algarismos inteiros, sem letras!")
    quantidade = 0

print("Fluxo segue em segurança com quantidade =", quantidade)

Saída: Erro: digite apenas algarismos inteiros, sem letras! / Fluxo segue em segurança com quantidade = 0

Texto recebido em int(texto)O que acontece no bloco tryO bloco except ValueError executa?
"25"Converte para 25 normalmente e conclui o try.Não (é pulado).
"abc" ou "12,5" ou ""int() falha na hora e salta para o except.Sim (exibe a mensagem e recupera o programa).

3. Variáveis sinalizadoras (flags booleanas) #

Uma flag (bandeira sinalizadora) é uma variável booleana (True / False) usada para lembrar se uma condição foi cumprida ou se algum evento especial ocorreu durante um percurso.

Combinando uma flag entrada_valida = False com while not entrada_valida: e try/except, construímos um leitor à prova de letras e de valores fora de faixa.

Python
entrada_valida = False
tentativa = 1

while not entrada_valida:
    texto = "erro" if tentativa == 1 else "15"
    try:
        qtd = int(texto)
        if qtd > 0:
            entrada_valida = True
        else:
            print("A quantidade deve ser maior que zero.")
    except ValueError:
        print(f"Tentativa {tentativa} ('{texto}') rejeitada: não é inteiro.")
    tentativa = tentativa + 1

print("Quantidade aceita:", qtd)

Saída: Tentativa 1 ('erro') rejeitada: não é inteiro. / Quantidade aceita: 15

4. Controle fino de laços: break e continue #

Dentro de um laço while ou for, duas instruções permitem alterar o fluxo da repetição:

• break: interrompe o laço inteiro imediatamente e salta para a primeira linha após o laço.

• continue: ignora apenas as linhas restantes da volta atual e volta imediatamente para o topo do laço (para a próxima repetição).

Python
# Processando 4 lançamentos: 30, -5 (inválido -> ignorar), 20, 0 (parar)
soma = 0
validos = 0

for passo in range(1, 5):
    valor = 30 if passo == 1 else (-5 if passo == 2 else (20 if passo == 3 else 0))
    if valor == 0:
        print("Código 0 encontrado: encerrando leitura com break.")
        break
    if valor < 0:
        print("Valor negativo ignorado com continue:", valor)
        continue
    soma = soma + valor
    validos = validos + 1

print("Válidos somados:", validos, "| Total:", soma)

Saída: Valor negativo ignorado com continue: -5 / Código 0 encontrado: encerrando leitura com break. / Válidos somados: 2 | Total: 50

InstruçãoEfeito na volta atualEfeito nas próximas voltas do laçoUso típico
continueInterrompe a volta atual neste ponto.Mantém o laço vivo e avança para a próxima volta.Descartar lançamentos inválidos sem sair do laço.
breakInterrompe a volta atual neste ponto.Cancela todas as voltas restantes e sai do laço.Encerrar busca ou sair de um menu quando a opção é 0.

5. Menus interativos persistentes #

Um sistema de balcão da Lojas Blue não fecha após atender uma única consulta: ele exibe o menu de opções, executa a operação escolhida (com match/case ou if/elif/else) e volta a exibir o menu até que o operador escolha a opção 0 (Sair).

Python
estoque = 20
# Simulando duas escolhas no menu: opção 1 (vender 4) e depois opção 0 (sair)
passo = 1

while True:
    opcao = 1 if passo == 1 else 0
    match opcao:
        case 1:
            estoque = estoque - 4
            print("Venda registrada. Estoque atual:", estoque)
        case 0:
            print("Encerrando sistema do caixa.")
            break
        case _:
            print("Opção inválida!")
    passo = passo + 1

Saída: Venda registrada. Estoque atual: 16 / Encerrando sistema do caixa.

6. Boas práticas: quando usar condição explícita vs. break #

Evite espalhar vários break ocultos no meio de um laço longo. Sempre que a condição de parada for simples (como while opcao != 0: ou while tentativa <= 3:), deixá-la visível no próprio cabeçalho do while torna o código mais fácil de ler e de testar no papel.

Python
tentativas_restantes = 3
acesso_liberado = False

while tentativas_restantes > 0 and not acesso_liberado:
    senha_digitada = "1234" if tentativas_restantes == 2 else "0000"
    if senha_digitada == "1234":
        acesso_liberado = True
    else:
        tentativas_restantes = tentativas_restantes - 1

print("Acesso liberado?", acesso_liberado)

Saída: Acesso liberado? True
