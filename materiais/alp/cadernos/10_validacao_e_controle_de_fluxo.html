Entenda a ideia

Formato válido não garante domínio válido

Converter uma entrada para inteiro responde se o texto pode representar um inteiro. Isso não garante que o número seja permitido: uma quantidade negativa pode ter formato válido e domínio inválido. Trate essas duas perguntas separadamente. Proteja a conversão com try/except ValueError quando a atividade exigir tolerância a textos inválidos; depois confira a faixa aceita.

Laços de tentativa precisam de saídas claras

Um leitor pode repetir até receber um valor válido ou até atingir um limite de tentativas. Defina como a tentativa é contada e o que acontece ao falhar. break encerra o laço mais próximo; continue abandona o restante da repetição atual e volta ao próximo teste. Posicionar uma atualização depois de continue pode fazer com que ela nunca ocorra.

Validação protege a operação e o estado

Em uma retirada, recusar uma quantidade não pode reduzir o saldo. Faça a verificação antes de alterar a variável. Se uma regra exige número finito, considere que float também pode aceitar textos como inf e nan; uma aplicação que trabalha com medições válidas precisa verificar essa condição explicitamente. Valide o que o contrato pede e apresente mensagens que expliquem como corrigir a entrada.

Erros para observar

Capturar todo erro sem critério; usar uma variável depois de conversão fracassada; pular a atualização com continue em um while; apagar uma flag que registra ocorrência; pedir nova entrada depois da opção sair.

# 03 — Sentinela e ausência de dados
# Objetivo: Separar encerramento, validação e processamento.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: -1 encerra; outros negativos são recusados; zero é um dado válido.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   -2
#   0
#   6
#   -1
# Confira na saída: 'Média: 3.0'

quantidade = 0
soma = 0.0
valor = float(input("Valor não negativo; -1 encerra: "))
while valor != -1:
    # float("inf") representa infinito positivo, usado como limite aberto.
    # A comparação exige valor finito e não negativo. Não estamos
    # estudando operações com infinito; apenas recusando entradas especiais.
    if 0 <= valor < float("inf"):
        soma += valor
        quantidade += 1
    else:
        print("Valor não finito ou negativo recusado.")
    valor = float(input("Valor não negativo; -1 encerra: "))
if quantidade == 0:
    print("Nenhum dado válido.")
else:
    print("Média:", soma / quantidade)
# Pressupõe conversão numérica válida; foco no protocolo da sentinela.

# 06 — Pular uma iteração com continue
# Objetivo: Ignorar entradas sem encerrar o processamento.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: continue salta para a próxima volta do laço.
# Como estudar: preveja a saída, execute e altere um valor por vez.

#   -1
#   2
#   0
#   3
# Confira na saída: 'Soma: 5'

soma = 0
aceitos = 0
for ordem in range(1, 5):
    valor = int(input(f"Inteiro {ordem}: "))
    if valor < 0:
        print("Negativo ignorado")

    soma += valor
    aceitos += 1
print("Aceitos:", aceitos)

while executando:
    print("1: adicionar ponto | 2: consultar | 0: sair")
    opcao = input("Opção: ")
    match opcao:
        case "1":
            pontos += 1
        case "2":
            print("Pontos:", pontos)
        case "0":
            executando = False
        case _:
            print("Opção inválida")

Retirada com validação — cenário didático Lojas BlueBaixar este exemplo .py
# Retirada com validação — cenário didático Lojas Blue
# Objetivo: Recusar formato, sinal e saldo insuficiente antes de alterar estado.
# Pré-requisito: tópicos anteriores e exemplos anteriores deste tópico.
# Estude: preveja o resultado, execute e altere um dado por vez.
# Confira na saída: 'Saldo final: 15'
# Entradas guiadas, uma por solicitação:
#   abc
#   0
#   19
#   3

saldo = 18
while True:
    try:
        retirada = int(input("Retirada inteira positiva, até 18: "))
    except ValueError:
        print("Formato inválido")
        continue
    if retirada <= 0 or retirada > saldo:
        print("Retirada recusada; saldo preservado")
        continue
    saldo -= retirada
    break
print("Saldo final:", saldo)
