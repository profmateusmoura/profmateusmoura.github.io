Percurso deste caderno #

Todo programa precisa comunicar resultados de maneira clara. Antes de guardar valores em variáveis ou realizar cálculos, o primeiro passo na programação é compreender como o Python executa instruções de cima para baixo e como controlar exatamente o que aparece na tela com a função print().

Pré-requisito: Nenhum conhecimento prévio de programação; apenas abrir, editar e executar um arquivo .py.

Conceito-chaveO que você vai dominar neste caderno
Ordem de execuçãoAs instruções são lidas e executadas de cima para baixo, uma linha por vez.
Literais de textoAs aspas indicam ao Python onde um texto começa e termina; elas não saem impressas.
Vários argumentosA vírgula dentro de print(a, b) separa argumentos e insere um espaço padrão entre eles.
Parâmetros sep e endsep altera o separador entre argumentos; end altera o que acontece no final da chamada.

1. Instruções e ordem de execução #

Um programa em Python é uma sequência de instruções escritas para o computador executar. Quando iniciamos um arquivo .py, o interpretador lê o código da primeira linha até a última, na ordem exata em que foi escrito, sem pular etapas e sem reorganizar frases por conta própria.

Na abertura de um caixa da Lojas Blue, por exemplo, o cabeçalho do terminal precisa exibir primeiro o nome da rede, depois o setor e, por fim, o status de atendimento. Cada chamada de print() produz uma linha completa e posiciona o cursor na linha de baixo.

Python
print("Lojas Blue")
print("Setor: Perfumaria")
print("Caixa 01 liberado")

Saída: Lojas Blue / Setor: Perfumaria / Caixa 01 liberado (uma frase em cada linha).

Se você inverter a ordem de duas linhas no arquivo .py, a ordem das mensagens na tela mudará exatamente da mesma forma. O computador não interpreta a intenção estética do autor: ele cumpre a sequência de comandos.

1º passoprint("Lojas Blue")Lojas BlueInício da 2ª linha
2º passoprint("Setor: Perfumaria")Setor: PerfumariaInício da 3ª linha

NO MUNDO FÍSICO

Pense em uma impressora térmica de cupons fiscais: cada print() padrão imprime a linha solicitada e avança o rolo de papel um passo para baixo.

2. print e textos literais #

Para que o Python saiba que uma palavra é um texto a ser exibido — e não o nome de um comando da linguagem —, precisamos envolvê-la com aspas simples ('...') ou aspas duplas ("..."). Esse trecho delimitado por aspas chama-se literal de texto (ou string).

As aspas externas funcionam apenas como moldura no código-fonte: elas dizem ao Python onde o texto começa e onde termina, mas não aparecem na saída. Além disso, chamar print() com parênteses vazios é totalmente válido e produz uma linha em branco, muito útil para separar blocos visuais de um comprovante.

Python
print("Comprovante de atendimento")
print()
print('Unidade Centro - Belo Horizonte')

Saída: Comprovante de atendimento / [linha em branco] / Unidade Centro - Belo Horizonte

Escrita no códigoÉ válida?O que acontece
print("Lojas Blue")SimExibe Lojas Blue sem as aspas.
print('Lojas Blue')SimExibe Lojas Blue (aspas simples e duplas têm o mesmo efeito).
print()SimImprime uma linha vazia (apenas a quebra de linha).
print(Lojas Blue)Não (SyntaxError / NameError)Sem aspas, o Python tenta procurar comandos ou variáveis com esses nomes.
ATENÇÃO

Sempre feche o texto com o mesmo tipo de aspas usado na abertura. Abrir com aspas duplas e fechar com aspas simples causa SyntaxError: unterminated string literal.

3. Vários argumentos na mesma chamada #

Uma única chamada de print() pode receber vários valores separados por vírgula. Cada valor passado dentro dos parênteses é chamado de argumento.

Quando separamos argumentos por vírgula — fora das aspas —, o Python exibe todos na mesma linha e insere automaticamente um espaço em branco entre cada par de argumentos. Não é necessário acrescentar espaços extras no final de cada palavra.

Python
print("Produto:", "Shampoo Neutro")
print("Setor:", "Cosméticos", "Corredor:", 3)
print(10, 20, 30)

Saída: Produto: Shampoo Neutro / Setor: Cosméticos Corredor: 3 / 10 20 30

ChamadaQuantidade de argumentosSaída produzidaPor que sai assim
print("A, B")1 argumentoA, BA vírgula está dentro das aspas: faz parte do próprio texto.
print("A", "B")2 argumentosA BA vírgula separa argumentos; print insere 1 espaço entre eles.
print("A", "B", "C")3 argumentosA B CUm espaço automático entre o 1º e o 2º, e outro entre o 2º e o 3º.
DISTINÇÃO IMPORTANTE

Passar vários argumentos para print('A', 'B') apenas exibe os valores em sequência na tela; isso não cria uma lista nem guarda os valores na memória.

4. Controlando o separador com sep #

Nem sempre queremos que vários argumentos sejam separados por um espaço simples. Ao exibir uma data (10/05/2026), um código de etiqueta (BLU-204-A) ou um caminho de menu (Estoque > Perfumaria > Reposição), precisamos substituir o espaço padrão por outro texto.

O parâmetro nomeado sep= permite definir qual texto aparecerá entre um argumento e o seguinte. Ele deve ser escrito após os argumentos normais, separado por vírgula.

Python
print("10", "05", "2026", sep="/")
print("BLU", "204", "MG", sep="-")
print("Estoque", "Perfumaria", "Vitrine", sep=" -> ")
print("R$", "29,90", sep="")

Saída: 10/05/2026 / BLU-204-MG / Estoque -> Perfumaria -> Vitrine / R$29,90

Valor de sepExemplo de chamadaSaídaQuando usar
Padrão (sep=" ")print("Dia", 10)Dia 10Frases comuns em que palavras devem ficar separadas por espaço.
sep="/" ou sep="-"print("10", "05", "2026", sep="/")10/05/2026Datas, horários (sep=':'), códigos de barras e protocolos.
sep=" -> "print("Caixa", "Pagamento", sep=" -> ")Caixa -> PagamentoTrilhas de navegação, etapas de atendimento e cabeçalhos.
sep="" (vazio)print("Item #", 42, sep="")Item #42Colar dois argumentos sem nenhum espaço intermediário.
ERRO COMUM

Se uma chamada tiver apenas um argumento, como print('Lojas Blue', sep='-'), o separador não aparece nenhuma vez, pois sep só entra entre dois argumentos.

5. Controlando o final da linha com end #

Por padrão, toda chamada de print() termina enviando uma quebra de linha invisível (representada por "\n"). É por isso que o próximo print() começa na linha de baixo.

Quando especificamos o parâmetro end=, substituímos essa quebra de linha final pelo texto desejado. Assim, duas ou mais chamadas consecutivas de print() podem construir uma única linha na tela.

Python
print("Atendimento: ", end="")
print("aberto")

print("10", "05", "2026", sep="-", end=" | ")
print("Lojas Blue")

Saída: Atendimento: aberto / 10-05-2026 | Lojas Blue

ParâmetroOnde atuaValor padrãoEfeito ao alterar
sepEntre os argumentos do mesmo print" " (um espaço)Muda a colagem interna entre arg1, arg2, arg3.
endApós o último argumento do print"\n" (nova linha)Mantém o cursor na mesma linha ou adiciona um sufixo antes do próximo print.

6. Aspas visíveis e quebras de linha no texto #

E quando precisamos que as próprias aspas apareçam impressas na mensagem, como ao destacar o nome de uma campanha (Promoção "Semana Blue")? Se usarmos aspas duplas por fora e também por dentro sem cuidado, o Python achará que o texto terminou antes da hora.

A solução mais limpa em Python é alternar os delimitadores: usar aspas simples por fora quando o texto contiver aspas duplas, ou usar aspas duplas por fora quando o texto contiver aspas simples. Também podemos usar a sequência especial \n dentro do texto sempre que quisermos forçar uma quebra de linha, ou \" para escapar aspas.

Python
print('Campanha "Semana Blue" ativa no caixa.')
print("Setor d'Água e Perfumaria")
print("Linha 1 do cupom\nLinha 2 do cupom")

Saída: Campanha "Semana Blue" ativa no caixa. / Setor d'Água e Perfumaria / Linha 1 do cupom / Linha 2 do cupom

Objetivo na telaForma recomendada no códigoExplicação
Mostrar aspas duplas: "Blue"'Promoção "Blue"'Aspas simples delimitam por fora; aspas duplas ficam visíveis dentro.
Mostrar aspas simples: 'Blue'"Promoção 'Blue'"Aspas duplas delimitam por fora; aspas simples ficam visíveis dentro.
Quebrar linha no meio de um texto" Topo\nBase"O par \n representa um salto de linha imediato na saída.
REGRA DE LEITURA

Ao fazer teste de mesa de um print(), pergunte sempre três coisas na ordem: 1) Quais são os argumentos? 2) Qual é o sep entre eles? 3) Qual é o end ao final da chamada?
