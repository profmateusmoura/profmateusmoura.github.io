Como estudar este caderno

Leia as seções na ordem. Cada uma desenvolve uma ideia, mostra como ela aparece no código e explica o resultado. Os códigos curtos do texto são exemplos de leitura; o pacote ZIP reúne os programas completos e os exercícios para praticar depois.

Antes de executar um código, preveja o que será exibido. Compare a previsão com a explicação e observe qual instrução produz cada mudança. Não é necessário acertar de primeira: localizar a diferença faz parte do estudo.

No mundo físico

Escreva cada mensagem em um cartão e coloque os cartões em uma coluna. Ler de cima para baixo representa a execução sequencial. Trocar os cartões muda a ordem da saída.

1. Um programa é uma sequência de instruções

Imagine preparar um cartaz de atendimento das Lojas Blue. Antes de calcular preços ou receber pedidos, o programa precisa comunicar algo. Uma instrução print exibe uma mensagem. Duas instruções são executadas de cima para baixo: a ordem das linhas no código determina a ordem das mensagens na saída. Escreva um arquivo com extensão .py, salve e execute. O editor mostra o código; o terminal mostra o resultado da execução.

2. Do cartaz no papel para a saída do programa

Pense em três linhas de um cartaz: o nome da loja, o setor e uma orientação. Quem escreve o cartaz escolhe tanto as palavras quanto a ordem em que elas aparecem. No programa, cada chamada de print corresponde a uma ação de apresentação. O computador não reorganiza as mensagens para que façam sentido: ele segue a ordem que você escreveu. Essa previsibilidade é o primeiro modelo de execução que vamos usar em todo o curso.

Antes de executar, cubra a parte da saída e leia o código de cima para baixo. Ao trocar duas instruções de lugar, os textos continuam os mesmos, mas a comunicação muda. Não é necessário criar variáveis para essa experiência; estamos trabalhando com mensagens fixas.

Python · exemplo explicado
print("Lojas Blue")
print("Setor de cosméticos")
print("Aguarde o atendimento")
Resultado
Lojas Blue
Setor de cosméticos
Aguarde o atendimento

Como ler a execução

A primeira linha do código produz a primeira linha do resultado. Cada print usa seu final padrão, que encerra a linha. O nome print, os parênteses e as aspas são partes da instrução; a mensagem entre aspas é o conteúdo apresentado.

3. Aspas delimitam o texto

Em print("Bem-vindo"), as aspas indicam onde começa e termina um texto literal. Elas não aparecem na saída. Já uma aspa que faz parte da mensagem precisa estar dentro de outra delimitação válida. Letras fora de aspas são interpretadas como nomes do programa; nesta etapa, escrevemos as mensagens como textos literais. Espaços dentro das aspas pertencem ao conteúdo e são preservados.

4. Separar argumentos não é separar chamadas

Uma vírgula entre dois argumentos pertence à sintaxe da chamada; ela não será impressa automaticamente. O separador padrão é um espaço. Se quiser uma barra, um hífen ou nenhum espaço, indique esse texto em sep. Já duas chamadas de print são duas instruções, cada uma com seu próprio encerramento.

Um engano frequente é tentar usar sep para unir duas linhas produzidas por chamadas diferentes. O separador só atua dentro da chamada que o recebeu. Para continuar a próxima chamada na mesma linha, a responsabilidade é de end. Leia sempre o alcance da alteração: ela vale para aquela chamada, não modifica definitivamente o comportamento de print.

Python · exemplo explicado
print("Produto", "Shampoo", sep=": ")
print("Situação", end=" → ")
print("disponível")
Resultado
Produto: Shampoo
Situação → disponível

Como ler a execução

Na primeira chamada, ": " entra entre os dois argumentos. Na segunda, " → " ocupa o lugar da quebra de linha final. A terceira volta a usar o encerramento padrão.

5. Separadores e finais de linha

print pode receber vários textos separados por vírgulas. Por padrão, há um espaço entre eles e uma quebra de linha ao final. sep altera o separador entre argumentos; end altera o que vem depois do último argumento. São responsabilidades diferentes: mudar sep não retira a quebra final. Use duas chamadas consecutivas para perceber o efeito de end. Uma linha em branco também é saída e pode ser produzida com print().

6. Quebra de linha e aspas dentro da mensagem

Uma mensagem também pode conter uma quebra de linha explícita. No código, a sequência barra invertida seguida de n representa essa quebra dentro do texto. Ela não é a letra n solta nem duas linhas de instruções. Compare isso com duas chamadas: o resultado visual pode ser equivalente, embora a organização do código seja diferente.

Para mostrar aspas, uma possibilidade simples é delimitar o texto com aspas simples e escrever aspas duplas dentro dele. O importante é não encerrar o texto antes do ponto desejado. Quando houver um erro de sintaxe, confira se cada abertura de aspas e de parênteses possui seu fechamento.

Python · exemplo explicado
print("Nome: Shampoo\nSetor: Higiene")
print('Mensagem: "Volte sempre"')
Resultado
Nome: Shampoo
Setor: Higiene
Mensagem: "Volte sempre"

Como ler a execução

A primeira instrução contém uma única string, mas produz duas linhas. Na segunda, as aspas simples delimitam o texto e as duplas fazem parte da mensagem.
