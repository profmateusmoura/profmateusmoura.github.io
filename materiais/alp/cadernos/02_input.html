Percurso deste caderno #

Um programa que exibe apenas textos fixos produz sempre o mesmo resultado. Para interagir com o operador de caixa ou com o cliente da Lojas Blue, o programa precisa pausar sua execução, aguardar que a pessoa digite uma informação no teclado e utilizar o texto digitado. Neste caderno, estudamos o funcionamento puro de input() integrado diretamente ao print(), antes mesmo de introduzirmos variáveis.

Pré-requisito: Caderno 01 (Saída de dados com print, sep e end).

Conceito-chaveO que você vai dominar neste caderno
Pausa de execuçãoinput() interrompe o programa até que o usuário digite uma linha e pressione Enter.
Prompt de orientaçãoO texto passado dentro de input('...') funciona como aviso antes da digitação.
Avaliação de dentro para foraEm print(input('...')), a leitura interna termina primeiro e entrega o texto ao print.
Tipo retornadoTudo o que vem de input() chega ao programa como texto (str).

1. Como o programa recebe dados do teclado #

Quando o Python encontra a chamada input(), ele para imediatamente a execução daquela linha e fica aguardando o usuário no terminal. Enquanto a tecla Enter não for pressionada, nenhuma instrução seguinte é executada.

Assim que o usuário digita uma sequência de caracteres e pressiona Enter, a função input() conclui seu trabalho e devolve exatamente o texto digitado (sem incluir a quebra de linha do Enter).

Python
print("Iniciando atendimento na Lojas Blue...")
print(input())
print("Atendimento registrado.")

Saída: Iniciando atendimento na Lojas Blue... / [usuário digita: Filial Centro] / Filial Centro / Atendimento registrado.

MomentoEstado do programaO que aparece na tela
1. Primeiro printExecutando normalmenteIniciando atendimento na Lojas Blue...
2. Durante input()Pausado aguardando tecladoCursor piscando à espera de digitação + Enter
3. Após pressionar Enterinput() entrega o texto ao print()Repete na tela o texto digitado (Filial Centro)
4. Último printRetoma a sequência e encerraAtendimento registrado.
NO MUNDO FÍSICO

Pense em um atendente que faz uma pergunta ao cliente no balcão e aguarda a resposta verbal antes de preencher o formulário. Sem a resposta do cliente, o atendimento não avança para o próximo passo.

2. A mensagem de orientação (prompt) #

Se chamarmos input() sem nenhum argumento, a tela ficará parada com o cursor piscando sem explicar o que a pessoa deve digitar. Quem usa o programa pode achar que o computador travou.

Por isso, passamos um texto orientador (chamado de prompt) dentro dos parênteses de input("..."). O Python exibe esse aviso sem quebrar linha e deixa o cursor logo à frente para o usuário digitar. Incluir dois-pontos e um espaço no final do prompt (como "Cidade: ") evita que a resposta digitada fique colada na pergunta.

Python
print(input("Digite o nome da filial: "))
print(input("Digite o setor de atendimento: "))

Saída: Digite o nome da filial: [usuário digita Savassi] → Savassi / Digite o setor de atendimento: [usuário digita Cosméticos] → Cosméticos

Escrita do promptComo fica durante a digitaçãoAvaliação didática
input()Savassi (sem pergunta prévia)Ruim: o operador não sabe o que o sistema está pedindo.
input("Filial:")Filial:SavassiRegular: falta espaço após os dois-pontos, colando a resposta.
input("Filial: ")Filial: SavassiExcelente: pergunta clara e resposta visualmente separada.
ATENÇÃO

O texto do prompt pertence ao momento da pergunta; ele não faz parte do valor devolvido por input(). Se o prompt é 'Filial: ' e o usuário digita 'Centro', o valor devolvido por input() é apenas 'Centro'.

3. Ordem de avaliação: de dentro para fora #

Quando escrevemos uma função dentro dos parênteses de outra, como em print(input("Produto: ")), o Python precisa descobrir qual é o argumento antes de conseguir imprimi-lo.

Por essa razão, a avaliação ocorre de dentro para fora: primeiro a chamada interna input("Produto: ") exibe o prompt, aguarda o usuário e devolve o texto digitado; somente depois a chamada externa print(...) recebe esse texto pronto e o exibe na saída.

Python
# Passo 1: input("Produto consultado: ") pede e lê o texto
# Passo 2: print(...) recebe o texto lido e o imprime
print(input("Produto consultado: "))

Saída: Prompt: Produto consultado: [usuário digita Sabonete Líquido] → Saída de print: Sabonete Líquido

EtapaExpressão no códigoO que está acontecendo
1ª etapaprint(input("Produto consultado: "))print é chamado, mas precisa aguardar o resultado do seu argumento.
2ª etapainput("Produto consultado: ")Exibe 'Produto consultado: ', pausa e lê 'Sabonete Líquido'.
3ª etapaprint("Sabonete Líquido")Com o argumento resolvido, print exibe 'Sabonete Líquido' e quebra a linha.

4. Combinando rótulos fixos com input() #

Como input() devolve um texto comum, podemos passá-lo como um dos argumentos de um print() que também possui rótulos fixos, além de usar sep= e end= aprendidos no Caderno 01.

Dessa forma, o programa solicita o dado com o prompt e, logo em seguida, monta uma frase formatada combinando textos literais com a resposta recém-digitada.

Python
print("Cliente atendido:", input("Nome do cliente: "))
print("[Setor", input("Informe o setor: "), "liberado]", sep=" - ")

Saída: Nome do cliente: [Ana] → Cliente atendido: Ana / Informe o setor: [Perfumaria] → [Setor - Perfumaria - liberado]

Argumento 1 de printArgumento 2 de printsep utilizadoLinha final exibida por print
"Cliente atendido:"Resultado de input() → "Ana"" " (padrão)Cliente atendido: Ana
"[Setor"Resultado de input() → "Perfumaria" (+ 3º arg)" - "[Setor - Perfumaria - liberado]
CUIDADO CONCEITUAL

A função print() aceita sep= e end=, mas a função input() aceita no máximo UM argumento de texto (o prompt). Escrever input('Nome', 'Sobrenome') ou input('Nome: ', end='') causa TypeError.

5. Múltiplas leituras em sequência #

Um roteiro de triagem pode realizar duas ou mais leituras consecutivas. Cada chamada de input() fará sua própria pausa independente, aguardando seu próprio Enter.

Se um único print() contiver dois input() separados por vírgula, o Python resolverá os argumentos da esquerda para a direita: fará a primeira pergunta, aguardará o primeiro Enter, fará a segunda pergunta, aguardará o segundo Enter e, só então, imprimirá a linha combinada.

Python
print("Resumo da etiqueta:")
print("Produto:", input("Digite o produto: "))
print("Unidade:", input("Digite a filial: "))

Saída: Resumo da etiqueta: / Digite o produto: [Shampoo] / Produto: Shampoo / Digite a filial: [Contagem] / Unidade: Contagem

6. O limite desta etapa: tudo é texto e nada fica salvo #

Há dois fatos essenciais sobre o que fizemos até aqui. Primeiro: input() sempre devolve texto (str), mesmo que o usuário digite números como 42 ou 19.90. Segundo: quando colocamos input() direto dentro de print(), o texto lido é exibido uma única vez e desaparece logo depois.

Se precisarmos usar o nome do produto em três linhas diferentes do cupom, ou transformar a quantidade digitada em número para multiplicá-la pelo preço, precisaremos guardar o valor lido em algum lugar da memória. É exatamente esse o papel das variáveis e conversões de tipo, que estudaremos no Caderno 03.

Python
# Mesmo digitando 105, input() devolve o texto "105"
print("Código lido:", input("Digite o código numérico: "))

Saída: Digite o código numérico: [105] → Código lido: 105

O que o usuário digitaO que input() devolveO que acontece após print(input(...))
Perfumaria"Perfumaria" (str)É exibido na tela e descartado em seguida.
105"105" (str — texto com algarismos)É exibido na tela; ainda não pode ser somado sem conversão.
Enter vazio (sem digitar nada)"" (string vazia)print recebe um texto vazio e imprime apenas a quebra de linha.
