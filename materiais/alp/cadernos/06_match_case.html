No mundo físico

Imagine um atendente que consulta o código de uma opção e executa a tarefa correspondente. Um código desconhecido precisa de uma resposta própria.

1. Escolher por um valor conhecido

Um menu pode oferecer códigos como 1 para consultar e 2 para encerrar. match avalia um valor e procura um case compatível. Neste curso, usamos alternativas literais escalares: números e textos, sem padrões de coleções. O recurso exige Python 3.10 ou superior. Primeiro confirme o tipo da opção: o inteiro 1 não é o mesmo que o texto "1".

2. O tipo da opção também participa da escolha

O menu pode mostrar um algarismo, mas input entrega texto. Portanto, é preciso escolher uma convenção: comparar a resposta com textos como "1" ou converter previamente para inteiro e comparar com 1. Misturar essas convenções faz uma opção aparentemente correta não corresponder ao case esperado.

Neste tópico, os valores de demonstração são escalares e as alternativas são literais. Observe a diferença antes de acrescentar qualquer leitura. A conversão de um texto inválido envolve uma validação própria; a seleção por case não é responsável por corrigir automaticamente o tipo.

Python · exemplo explicado
opcao = "1"
match opcao:
    case 1:
        print("Número inteiro")
    case "1":
        print("Texto")
Resultado
Texto

Como ler a execução

A opção é uma string. O literal inteiro do primeiro case não corresponde ao texto do segundo.

3. Cada alternativa tem um bloco

A indentação organiza os comandos de cada case. Quando uma alternativa corresponde, seu bloco é executado e o programa continua após o match. Não é necessário escrever break para impedir que o próximo case execute. O caso _ representa a alternativa geral e deve ficar ao final, para tratar valores não previstos.

4. Alternativas compartilhadas e caso padrão

Duas opções podem levar ao mesmo comportamento. Uma alternativa com | permite reunir valores literais em um case. Isso não é o operador lógico or de uma expressão booleana comum: aqui ele descreve possibilidades de correspondência. O caso geral _ fica no final e dá uma resposta para valores que não foram listados.

Uma seleção pode não executar nenhum bloco quando não há correspondência e não há caso geral. Em um menu didático, uma mensagem explícita costuma facilitar a compreensão de uma opção desconhecida. O programa não deve fingir que uma operação foi realizada quando a opção não foi reconhecida.

Python · exemplo explicado
opcao = "s"
match opcao:
    case "s" | "S":
        print("Confirmado")
    case "n" | "N":
        print("Cancelado")
    case _:
        print("Opção desconhecida")
Resultado
Confirmado

Como ler a execução

Os textos s e S levam ao mesmo bloco. Depois que ele executa, não há passagem automática para os demais cases.

5. Escolher entre if e match

match é útil quando se deseja comparar uma opção com valores discretos. Para testar intervalos e relações como quantidade > saldo, if costuma expressar melhor a regra. Não use seleção de menu como substituto de uma validação completa. Um código pode estar em um formato válido e ainda não representar uma opção permitida.

6. O que vem depois da seleção

Uma instrução alinhada com match está fora de todos os cases. Ela representa a continuação comum do programa. Isso é semelhante ao que vimos após um if: a indentação delimita o alcance de cada escolha.

Não use break apenas por ter estudado seleções em outra linguagem. Em Python, não há queda automática de um case para o seguinte. break tem relação com laços e só pode ser usado em um contexto em que um laço possa ser encerrado. Para testar intervalos, permaneça com as comparações de if; essa escolha costuma tornar a intenção mais direta.
