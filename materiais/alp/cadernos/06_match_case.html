Seleção com match/case

Selecionar alternativas por valores literais escalares.

Entenda a ideia

Escolher por um valor conhecido

Um menu pode oferecer códigos como 1 para consultar e 2 para encerrar. match avalia um valor e procura um case compatível. Neste curso, usamos alternativas literais escalares: números e textos, sem padrões de coleções. O recurso exige Python 3.10 ou superior. Primeiro confirme o tipo da opção: o inteiro 1 não é o mesmo que o texto "1".

Cada alternativa tem um bloco

A indentação organiza os comandos de cada case. Quando uma alternativa corresponde, seu bloco é executado e o programa continua após o match. Não é necessário escrever break para impedir que o próximo case execute. O caso _ representa a alternativa geral e deve ficar ao final, para tratar valores não previstos.

Escolher entre if e match

match é útil quando se deseja comparar uma opção com valores discretos. Para testar intervalos e relações como quantidade > saldo, if costuma expressar melhor a regra. Não use seleção de menu como substituto de uma validação completa. Um código pode estar em um formato válido e ainda não representar uma opção permitida.

Erros para observar

Tirar as aspas de opções textuais; tentar escrever uma comparação de intervalo como literal de case; esquecer o curinga; esperar que comandos em maiúsculas sejam automaticamente iguais aos minúsculos.

Um exemplo acompanhado

Leia o código antes de avançar. Cada passo explica uma mudança ou decisão. A simulação tem uma sequência fixa; os arquivos Python permitem experimentar outras entradas.

opcao = 2
match opcao:
    case 1:
        print("Consultar")
    case 2:
        print("Encerrar")
    case _:
        print("Opção inválida")

# 01 — Menu por valor exato
# Objetivo: Selecionar uma alternativa textual.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: match/case requer Python 3.10 ou superior.
# Como estudar: preveja a saída, execute e altere um valor por vez.

opcao = input("Digite 1 para iniciar ou 2 para ajuda: ")
# Comparamos texto porque não convertemos a entrada para int.
match opcao:
    case "1":
        print("Iniciando")
    case "2":
        print("Leia o enunciado antes de programar.")
    case _:
        # O curinga deve ficar por último.
        print("Opção inválida")

03 — Alternativas no mesmo casoBaixar este exemplo .py
# 03 — Alternativas no mesmo caso
# Objetivo: Agrupar valores literais com a mesma resposta.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: Dentro de case, | separa padrões alternativos; não é o or booleano.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   7
# Confira na saída: 'Fim de semana'

dia = int(input("Dia da semana, de 1 a 7: "))
# Convenção desta atividade: 1 é segunda e 7 é domingo.
match dia:
    case 1 | 2 | 3 | 4 | 5:
        print("Dia útil")
    case 6 | 7:
        print("Fim de semana")
    case _:
        print("Dia inválido")

# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.

        print("Atividade iniciada")

        print("Escolha um comando exibido no convite.")
    case "sair" | "SAIR":
        print("Até logo")
    case _:
        # Não usamos lower ou outras operações de strings.
        print("Comando não reconhecido")
05 — Calculadora de uma operaçãoBaixar este exemplo .py
# 05 — Calculadora de uma operação
# Objetivo: Combinar seleção e proteção de divisão.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: match seleciona o operador; if verifica uma condição dentro do caso.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   8
#   /
#   2
# Confira na saída: 'Resultado: 4.0'

a = float(input("Primeiro número: "))
operador = input("Operação (+, -, *, /): ")
b = float(input("Segundo número: "))
match operador:
    case "+":
        print("Resultado:", a + b)
    case "-":
        print("Resultado:", a - b)
    case "*":
        print("Resultado:", a * b)
    case "/":
        if b == 0:
            print("Divisor não pode ser zero.")
        else:
            print("Resultado:", a / b)
    case _:
        print("Operação inválida")
06 — Opções e faixasBaixar este exemplo .py
# 06 — Opções e faixas
# Objetivo: Escolher a estrutura adequada para cada decisão.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: Use valores literais em case e comparações de faixa em if.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   comum
#   10
# Confira na saída: 'Tarifa: 5.00'

modalidade = input("Modalidade: comum ou expresso: ")
# Tarifas inventadas apenas para exercitar decisões.
match modalidade:
    case "comum":
        # Só esta modalidade depende da distância.
        distancia = float(input("Distância em km, não negativa: "))
        if distancia <= 10:
            print("Tarifa: 5.00")
        else:
            print("Tarifa: 8.00")
    case "expresso":
        print("Tarifa: 12.00")
    case _:
        print("Modalidade inválida")
