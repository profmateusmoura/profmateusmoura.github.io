No mundo físico

Conserve uma folha com poucos campos — soma, quantidade e valor atual. Atualize um dado por vez para perceber que muitos algoritmos numéricos não precisam guardar todas as entradas.

1. Combinar mecanismos para resolver um problema

Conhecer a sintaxe de um laço não basta para calcular uma média ou identificar um número primo. Comece pelo contrato: quais entradas são aceitas, qual resultado é desejado e quais variáveis são necessárias. Na média de leituras, mantenha soma e quantidade; em extremos, acompanhe menor e maior. Inicializar o maior com zero só é adequado quando o domínio garante que isso não invalida o resultado.

2. Média: total e quantidade precisam descrever os mesmos dados

Para calcular uma média, some as leituras consideradas válidas e conte exatamente essas mesmas leituras. Se um valor foi ignorado pela regra do problema, ele não deve entrar em apenas uma das duas medidas. Ao final, verifique se a quantidade é maior que zero antes da divisão.

O padrão de soma e contagem reaparece em percentuais: a quantidade de ocorrências de uma condição é comparada ao total de observações. A unidade do resultado também muda. Uma razão de 0.25 corresponde a 25%, depois da multiplicação por 100. Não confunda contagem de ocorrências com soma dos valores observados.

3. Enxergar uma propriedade que permanece válida

Depois de processar cada leitura, a soma deve representar exatamente os valores já recebidos. Essa frase é uma propriedade de acompanhamento. Para contar divisores, o contador deve representar quantos candidatos já testados dividiram o número sem resto. Escrever essa propriedade ajuda a decidir onde inicializar, atualizar e apresentar o resultado.

4. Maior e menor: o primeiro dado pode ser a referência

Se todos os valores forem negativos, inicializar o maior com zero produzirá um resultado que nem sequer apareceu na entrada. Uma estratégia para uma sequência não vazia é usar a primeira leitura como maior e menor iniciais. As leituras seguintes só substituem essas referências quando satisfazem a comparação apropriada.

Empates exigem uma decisão adicional se o problema pede a quantidade de ocorrências do extremo. Ao encontrar um valor estritamente maior, troque o maior e reinicie a contagem em um. Ao encontrar um valor igual, incremente a contagem. Não reinicie esse contador para qualquer valor diferente; um valor menor não invalida as ocorrências do maior já conhecido.

5. Aprender famílias de estratégias

Os exemplos deste caderno exploram divisores, primalidade, fatorial, Fibonacci, MDC, MMC, algarismos e padrões. Não memorize uma receita única. Observe como o resto da divisão testa divisibilidade, como // remove o último algarismo de um inteiro não negativo e como variáveis auxiliares preservam um valor antes de uma atualização. Respeite o domínio declarado em cada problema: zero, negativos e entrada vazia podem exigir regras próprias.

6. Divisores e primalidade são perguntas relacionadas

Um inteiro positivo d divide n quando o resto n % d é zero. Podemos percorrer candidatos e contar quantos satisfazem essa condição. Um número primo é um inteiro maior que 1 que possui exatamente dois divisores positivos: 1 e ele próprio. Por essa definição, 1 não é primo.

Há estratégias mais eficientes que testar todos os números até n, mas primeiro precisamos compreender o contrato e verificar a solução direta. Um teste que procura um divisor entre 2 e n - 1 pode parar quando encontra o primeiro: basta um contraexemplo para provar que n não é primo.

Python · exemplo explicado
numero = 6
quantidade = 0
for candidato in range(1, numero + 1):
    if numero % candidato == 0:
        quantidade += 1
print(quantidade)
Resultado
4

Como ler a execução

Os divisores positivos são 1, 2, 3 e 6. A quantidade quatro mostra que 6 não atende à definição de primo.

7. Fatorial e Fibonacci: a atualização depende do estado anterior

No fatorial, acumulamos um produto. O valor inicial é 1, pois multiplicar por zero apagaria todo o resultado. O caso 0! também vale 1: um laço sem multiplicações deve preservar a inicialização. No Fibonacci, dois valores anteriores determinam o próximo, então precisamos preservar os dados antes de sobrescrevê-los.

A variável auxiliar não é um detalhe decorativo: ela guarda um resultado enquanto outras atribuições reorganizam os papéis das variáveis. Explique cada papel em voz alta — anterior, atual e próximo — e só então traduza para nomes. Atualizar o anterior cedo demais pode fazer a segunda conta usar um estado que não deveria existir ainda.

Python · exemplo explicado
anterior = 0
atual = 1
proximo = anterior + atual
anterior = atual
atual = proximo
print(anterior, atual)
Resultado
1 1

Como ler a execução

proximo é calculado com os valores antigos 0 e 1. Só depois as referências numéricas avançam para o próximo par.

8. MDC e MMC: reduzir o problema preservando uma propriedade

O algoritmo de Euclides substitui o par de inteiros pelo segundo valor e pelo resto da divisão. Essa transformação preserva o máximo divisor comum. Quando o segundo valor se torna zero, o primeiro contém o MDC. Trabalhe inicialmente com inteiros positivos para deixar o domínio claro.

Depois de encontrar o MDC, o MMC pode ser obtido por uma relação entre produto e divisor comum, respeitando o domínio definido. Não é necessário que cada problema tenha uma estratégia isolada: um algoritmo pode fornecer uma parte reutilizável de outro. A organização dessa reutilização em funções será aprofundada adiante.

Python · exemplo explicado
a = 18
b = 12
while b != 0:
    resto = a % b
    a = b
    b = resto
print(a)
Resultado
6

Como ler a execução

Os pares passam de (18, 12) para (12, 6) e depois (6, 0). A variável a guarda 6 quando a repetição termina.

numero = 123
soma = 0
while numero > 0:
    soma += numero % 10
    numero //= 10
print(soma)
