1. Troca de valores entre duas variáveis (swap) #

Suponha que os preços das vitrines A e B precisem trocar de lugar. Se fizermos simplesmente a = b e depois b = a, o valor original de a será perdido na primeira linha, e ambas terminarão com o valor de b!

O algoritmo universal de troca usa uma variável auxiliar (aux) para guardar temporariamente o valor antigo de a antes de sobrescrevê-lo.

Python
vitrine_a = 29.90
vitrine_b = 54.00

aux = vitrine_a       # 1. Salva o valor original de vitrine_a (29.90)
vitrine_a = vitrine_b # 2. vitrine_a recebe o valor de vitrine_b (54.00)
vitrine_b = aux       # 3. vitrine_b recebe o valor salvo em aux (29.90)

print("Vitrine A:", vitrine_a, "| Vitrine B:", vitrine_b)

Saída: Vitrine A: 54.0 | Vitrine B: 29.9

2. Maior e menor valor de uma sequência (sem coleções) #

Como descobrir o maior e o menor pedido do dia lendo um valor por vez, sem guardar todos em uma lista? O segredo está na inicialização correta: lemos o PRIMEIRO valor antes do laço e fazemos maior = primeiro e menor = primeiro.

Depois, no laço que lê do 2º valor em diante, comparamos cada novo valor lido com os recordes atuais: se novo > maior, atualizamos maior; se novo < menor, atualizamos menor.

Python
# Simulando a leitura de 4 pedidos: 28, 45, 19 e 52
primeiro = 28
maior = primeiro
menor = primeiro

for passo in range(2, 5):
    if passo == 2:
        lido = 45
    elif passo == 3:
        lido = 19
    else:
        lido = 52

    if lido > maior:
        maior = lido
    if lido < menor:
        menor = lido

print("Menor pedido:", menor, "| Maior pedido:", maior)

Saída: Menor pedido: 19 | Maior pedido: 52

CUIDADO CONCEITUAL

Nunca inicialize menor = 0 esperando ler números positivos! Como qualquer preço positivo é maior que 0, a condição lido < menor nunca seria verdadeira e o programa diria erroneamente que o menor preço foi 0.

3. Decomposição e inversão de dígitos na base 10 #

Para inspecionar os dígitos de um código numérico inteiro positivo sem convertê-lo para texto, usamos uma propriedade aritmética simples da base 10:

• n % 10 fornece o último algarismo (unidade) de n.

• n // 10 remove o último algarismo de n.

Repetindo essas duas operações em um while n > 0:, conseguimos somar todos os dígitos, contar quantos dígitos existem ou construir o número invertido (invertido = invertido * 10 + digito).

Python
n = 472
soma_digitos = 0
invertido = 0

while n > 0:
    digito = n % 10
    soma_digitos = soma_digitos + digito
    invertido = invertido * 10 + digito
    n = n // 10

print("Soma dos dígitos de 472:", soma_digitos)
print("Número invertido:", invertido)

Saída: Soma dos dígitos de 472: 13 / Número invertido: 274

4. Divisores, fatorial e números primos #

Um número inteiro d é divisor exato de n quando o resto da divisão é zero: n % d == 0. Percorrendo os candidatos de 1 até n com for d in range(1, n + 1):, podemos contar quantos divisores n possui.

Um número inteiro maior que 1 é primo quando possui exatamente 2 divisores positivos (1 e ele mesmo). Já o fatorial de n (n!) é o produto acumulado de 1 até n, inicializando o acumulador multiplicativo em 1 (produto = 1).

Python
numero = 7
qtd_divisores = 0

for d in range(1, numero + 1):
    if numero % d == 0:
        qtd_divisores = qtd_divisores + 1

eh_primo = (numero > 1) and (qtd_divisores == 2)
print(f"{numero} tem {qtd_divisores} divisores. É primo? {eh_primo}")

Saída: 7 tem 2 divisores. É primo? True

ATENÇÃO

Para somatórios, o acumulador começa em 0 (elemento neutro da adição). Para produtórios como fatorial ou potência, o acumulador deve começar em 1 (elemento neutro da multiplicação), pois se começar em 0 todo o produto ficará 0!

5. Máximo Divisor Comum (MDC de Euclides) #

Para dividir lotes de 48 sabonetes e 18 shampoos no maior número possível de kits idênticos sem sobra, precisamos do Máximo Divisor Comum (MDC) entre 48 e 18.

O algoritmo de Euclides calcula o MDC de forma rápida usando restos sucessivos: enquanto b != 0, calculamos resto = a % b, fazemos a = b e b = resto. Quando b chega a 0, o MDC está em a.

Python
a = 48
b = 18

while b != 0:
    resto = a % b
    a = b
    b = resto

print("Maior quantidade de kits iguais (MDC):", a)

Saída: Maior quantidade de kits iguais (MDC): 6

3ª12612 % 6 = 060 (encerra com MDC = 6)

6. Sequências iterativas (padrão Fibonacci) #

Em sequências onde cada novo termo depende dos dois termos imediatamente anteriores (como Fibonacci: 1, 1, 2, 3, 5, 8...), mantemos apenas duas variáveis de estado (anterior e atual), calculamos proximo = anterior + atual e deslizamos a janela fazendo anterior = atual e atual = proximo.

Python
anterior = 1
atual = 1
print(anterior, atual, end=" ")

for passo in range(4):
    proximo = anterior + atual
    print(proximo, end=" ")
    anterior = atual
    atual = proximo
print()

Saída: 1 1 2 3 5 8
