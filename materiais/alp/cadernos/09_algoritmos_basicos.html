Entenda a ideia

Combinar mecanismos para resolver um problema

Conhecer a sintaxe de um laço não basta para calcular uma média ou identificar um número primo. Comece pelo contrato: quais entradas são aceitas, qual resultado é desejado e quais variáveis são necessárias. Na média de leituras, mantenha soma e quantidade; em extremos, acompanhe menor e maior. Inicializar o maior com zero só é adequado quando o domínio garante que isso não invalida o resultado.

Enxergar uma propriedade que permanece válida

Depois de processar cada leitura, a soma deve representar exatamente os valores já recebidos. Essa frase é uma propriedade de acompanhamento. Para contar divisores, o contador deve representar quantos candidatos já testados dividiram o número sem resto. Escrever essa propriedade ajuda a decidir onde inicializar, atualizar e apresentar o resultado.

Aprender famílias de estratégias

Os exemplos deste caderno exploram divisores, primalidade, fatorial, Fibonacci, MDC, MMC, algarismos e padrões. Não memorize uma receita única. Observe como o resto da divisão testa divisibilidade, como // remove o último algarismo de um inteiro não negativo e como variáveis auxiliares preservam um valor antes de uma atualização. Respeite o domínio declarado em cada problema: zero, negativos e entrada vazia podem exigir regras próprias.

Erros para observar

Começar maior ou menor em zero arbitrário; iniciar produto em zero; classificar um como primo; perder um estado no Fibonacci; esquecer que zero possui um dígito; tentar preservar zeros à esquerda em um inteiro.

08 — MDC pelo algoritmo de EuclidesBaixar este exemplo .py
# 08 — MDC pelo algoritmo de Euclides
# Objetivo: Reduzir um problema usando restos sucessivos.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: MDC(a, b) é igual a MDC(b, a % b), enquanto b não for zero.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   48
#   18
# Confira na saída: 'MDC de 48 e 18: 6'

a = int(input("Primeiro inteiro positivo: "))
b = int(input("Segundo inteiro positivo: "))
# Trabalhamos com cópias para preservar as entradas na apresentação.
x = a
y = b
while y != 0:
    resto = x % y
    x = y
    y = resto
# O último divisor não nulo é o MDC.
print(f"MDC de {a} e {b}: {x}")
09 — MMC a partir do MDCBaixar este exemplo .py
# 09 — MMC a partir do MDC
# Objetivo: Reutilizar uma ideia algorítmica sem funções ainda.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: Para positivos, MMC(a,b) = (a // MDC(a,b)) * b.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   12
#   18
# Confira na saída: 'MMC: 36'

a = int(input("Primeiro inteiro positivo: "))
b = int(input("Segundo inteiro positivo: "))
x = a
y = b
while y != 0:
    resto = x % y
    x = y
    y = resto
mdc = x
# A divisão inteira é exata porque mdc divide a.
mmc = (a // mdc) * b
print("MMC:", mmc)
