No mundo físico

Separe 17 fichas em grupos de 5. Os grupos completos representam o quociente inteiro; as fichas restantes representam o resto.

1. Da situação à expressão

Uma reposição pode ser calculada pela diferença entre o mínimo desejado e o estoque atual. Antes de programar, identifique o significado de cada valor e sua unidade. Adição, subtração, multiplicação e divisão combinam números. / produz divisão real; // produz divisão pelo piso; % produz o resto. Use parênteses para tornar explícita a ordem desejada quando uma expressão combina operações.

2. Divisão, quociente e resto respondem perguntas diferentes

Considere 17 unidades que serão organizadas em caixas de 5. A divisão real informa uma razão, 3.4. A divisão inteira informa quantas caixas completas podem ser montadas, 3. O resto informa quantas unidades ficam fora dessas caixas, 2. Escolha o operador pela pergunta que deseja responder.

O exemplo usa inteiros não negativos. Com números negativos, // arredonda o quociente para baixo, e não simplesmente corta as casas decimais. Declare o domínio dos valores para não transportar uma interpretação de caixas para números que não representam quantidades válidas.

Python · exemplo explicado
unidades = 17
capacidade = 5
print(unidades / capacidade)
print(unidades // capacidade)
print(unidades % capacidade)
Resultado
3.4
3
2

Como ler a execução

As três expressões usam os mesmos dados, mas representam resultados diferentes. A verificação 3 × 5 + 2 = 17 reconstrói a quantidade inicial.

3. Comparações produzem respostas booleanas

Uma comparação como estoque < minimo produz True ou False. Ela não modifica o estoque. < e <= diferem justamente na fronteira de igualdade: se estoque é igual ao mínimo, apenas a segunda é verdadeira. == compara valores; = atribui. Leia a expressão em linguagem comum e teste valores abaixo, iguais e acima da fronteira.

4. Percentual e precedência precisam de uma fórmula explícita

Um desconto de dez por cento é uma fração do preço, não a subtração do número 10 em todos os casos. Primeiro transforme o percentual em proporção dividindo por 100; depois calcule o valor do desconto; por fim subtraia esse valor do preço. Separar as etapas em nomes ajuda a explicar a fórmula.

A multiplicação e a divisão são avaliadas antes da soma e subtração. Mesmo conhecendo essa precedência, use parênteses quando eles deixam clara a regra de negócio. Faça uma conferência com um preço simples antes de usar valores com casas decimais. A apresentação final com duas casas não corrige uma fórmula errada.

Python · exemplo explicado
preco = 80
percentual = 10
desconto = preco * (percentual / 100)
final = preco - desconto
print(f"{desconto:.2f}")
print(f"{final:.2f}")
Resultado
8.00
72.00

Como ler a execução

O desconto é 8, pois 10% de 80 equivale a 8. Subtrair 10 diretamente produziria 70 e expressaria outra regra.

5. Combinar condições com significado

and exige que as duas condições sejam verdadeiras; or permite que pelo menos uma seja; not nega a condição. Para uma retirada válida, a quantidade deve ser positiva e não exceder o saldo. A avaliação usa curto-circuito: em and, uma primeira parte falsa dispensa avaliar a segunda. Esse comportamento pode proteger uma divisão, desde que a verificação do divisor venha antes dela.

6. Curto-circuito: a primeira condição pode proteger a segunda

Ao avaliar and, Python já sabe que o resultado será falso se a primeira parte for falsa. Nesse caso, não precisa avaliar a segunda. Essa ordem pode ser usada para evitar uma operação sem sentido, como dividir por zero. A proteção só funciona quando vem antes da operação que depende dela.

Com or acontece a situação complementar: uma primeira parte verdadeira já determina o resultado. Não pense nesses operadores apenas como palavras de ligação; leia a ordem de avaliação e as condições necessárias para cada expressão ser segura.

Python · exemplo explicado
quantidade = 0
total = 100
print(quantidade != 0 and total / quantidade > 20)
Resultado
False

Como ler a execução

A comparação quantidade != 0 é falsa. A divisão não é executada. Inverter as duas partes faria o programa tentar dividir antes de conferir o divisor.
