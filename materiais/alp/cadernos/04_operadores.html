Da situação à expressão

Uma reposição pode ser calculada pela diferença entre o mínimo desejado e o estoque atual. Antes de programar, identifique o significado de cada valor e sua unidade. Adição, subtração, multiplicação e divisão combinam números. / produz divisão real; // produz divisão pelo piso; % produz o resto. Use parênteses para tornar explícita a ordem desejada quando uma expressão combina operações.

Comparações produzem respostas booleanas

Uma comparação como estoque < minimo produz True ou False. Ela não modifica o estoque. < e <= diferem justamente na fronteira de igualdade: se estoque é igual ao mínimo, apenas a segunda é verdadeira. == compara valores; = atribui. Leia a expressão em linguagem comum e teste valores abaixo, iguais e acima da fronteira.

Combinar condições com significado

and exige que as duas condições sejam verdadeiras; or permite que pelo menos uma seja; not nega a condição. Para uma retirada válida, a quantidade deve ser positiva e não exceder o saldo. A avaliação usa curto-circuito: em and, uma primeira parte falsa dispensa avaliar a segunda. Esse comportamento pode proteger uma divisão, desde que a verificação do divisor venha antes dela.

Erros para observar

Dividir por zero; esquecer a soma dos pesos na média ponderada; tratar 15 como a taxa fracionária de 15%; confundir = e ==. Com números negativos, // arredonda para baixo, não necessariamente em direção a zero.

O segundo teste nem sempre é avaliadoBaixar este exemplo .py
# O segundo teste nem sempre é avaliado
# Execução: python 04_operadores/exemplos/07_curto_circuito.py
# Confira na saída: 'Condição com divisor zero: False'
# Preveja o estado dos dados antes de executar; depois altere um caso de fronteira.

numerador = 8
divisor = 0
# and só precisa da segunda condição quando a primeira é verdadeira.
# Como divisor != 0 é False, a divisão à direita não será executada.
pode_calcular = divisor != 0 and numerador / divisor > 2
print("Condição com divisor zero:", pode_calcular)
divisor = 2
print("Condição com divisor dois:", divisor != 0 and numerador / divisor > 2)
# or encerra a avaliação assim que já houver uma condição verdadeira.
possui_convite = True
autorizado = possui_convite or numerador / 0 > 2
print("Autorização por convite:", autorizado)
# A divisão por zero acima é deliberada para observar o curto-circuito.
# Trocar a ordem das condições mudaria quais expressões chegam a ser avaliadas.
Divisão inteira, resto e truncamentoBaixar este exemplo .py
# Divisão inteira, resto e truncamento
# Execução: python 04_operadores/exemplos/08_divisao_e_truncamento.py
# Confira na saída: 'Reconstrução: -7'
# Preveja o estado dos dados antes de executar; depois altere um caso de fronteira.

numero = -7
divisor = 3
# / produz o quociente real aproximado. int descarta sua parte fracionária
# em direção a zero. //, por sua vez, arredonda o quociente para baixo.
print("Divisão real:", numero / divisor)
print("Truncamento com int:", int(numero / divisor))
print("Quociente com //:", numero // divisor)
print("Resto com %:", numero % divisor)
# Mesmo com dividendo negativo, a reconstrução conserva o número original.
quociente = numero // divisor
resto = numero % divisor
print("Reconstrução:", divisor * quociente + resto)
