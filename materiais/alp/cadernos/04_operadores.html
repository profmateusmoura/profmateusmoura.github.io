1. Operadores aritméticos fundamentais #

Os operadores aritméticos combinam números literais ou variáveis numéricas para produzir um novo valor. Calcular preco * quantidade não altera as variáveis originais; para guardar o resultado, precisamos atribuí-lo a uma variável.

Observe uma regra importante do Python: a divisão comum com barra simples (/) sempre devolve um float, mesmo quando a divisão é exata (como 10 / 2, que resulta em 5.0).

Python
preco_unitario = 25.0
quantidade = 4
desconto = 12.5

bruto = preco_unitario * quantidade
liquido = bruto - desconto
parcela = liquido / 2

print("Bruto:", bruto)
print("Líquido:", liquido)
print("Cada parcela (2x):", parcela)

Saída: Bruto: 100.0 / Líquido: 87.5 / Cada parcela (2x): 43.75

OperadorOperaçãoExemploResultadoTipo do resultado
+Adição15 + 419int (ou float se houver algum float)
-Subtração15 - 411int (ou float se houver algum float)
*Multiplicação15 * 460int (ou float se houver algum float)
/Divisão real15 / 2 e 8 / 27.5 e 4.0Sempre float

ATENÇÃO

Não confunda o operador de potenciação em Python (**) com o circunflexo (^). Em Python, 2 ** 3 calcula 2 elevado a 3 (8).

2. Divisão inteira (//) e resto da divisão (%) #

Em logística e operação de caixa, muitas vezes não queremos quebrar objetos ao meio com números decimais. Se temos 23 frascos de perfume e cada caixa de transporte comporta 5 frascos, queremos saber duas coisas inteiras: quantas caixas ficam completas e quantos frascos sobram avulsos.

O operador // (divisão inteira) devolve o quociente inteiro da divisão, enquanto o operador % (módulo ou resto) devolve exatamente o que sobrou. Esse mesmo par resolve conversão de minutos em horas e minutos, distribuição de cédulas de troco e teste de paridade (n % 2 == 0).

Python
unidades = 23
capacidade_caixa = 5

caixas_completas = unidades // capacidade_caixa
avulsas = unidades % capacidade_caixa

print("Caixas completas:", caixas_completas)
print("Unidades avulsas:", avulsas)
print("Conferência:", caixas_completas * capacidade_caixa + avulsas)

Saída: Caixas completas: 4 / Unidades avulsas: 3 / Conferência: 23

3. Precedência e uso de parênteses #

Quando uma expressão combina vários operadores, o Python não calcula simplesmente da esquerda para a direita: ele respeita uma hierarquia de precedência, assim como na matemática.

Ao calcular a média de duas vendas (venda1 + venda2) / 2, os parênteses são indispensáveis. Sem eles, venda1 + venda2 / 2 dividiria apenas venda2 por 2 antes de somar com venda1.

Python
sem_parenteses = 20 + 10 * 2
com_parenteses = (20 + 10) * 2

venda_manha = 80.0
venda_tarde = 120.0
media_correta = (venda_manha + venda_tarde) / 2

print("Sem parênteses:", sem_parenteses)
print("Com parênteses:", com_parenteses)
print("Média do dia:", media_correta)

Saída: Sem parênteses: 40 / Com parênteses: 60 / Média do dia: 100.0

Nível de prioridade (do mais alto ao mais baixo)OperadoresObservação
1º (mais forte)( ... )Parênteses sempre são resolvidos primeiro, de dentro para fora.
2º**Potenciação.
3º*, /, //, %Multiplicação, divisões e resto (avaliados da esquerda para a direita entre si).
4º+, -Adição e subtração.
5º==, !=, <, <=, >, >=Operadores relacionais (comparações).
6º (mais baixo)not, depois and, depois orOperadores lógicos.

4. Operadores relacionais (comparações) #

Operadores relacionais comparam dois valores e produzem sempre um resultado booleano: True (verdadeiro) ou False (falso). Eles são a base das tomadas de decisão que faremos a partir do Caderno 05.

Preste muita atenção na diferença entre um sinal de igual (=) e dois sinais de igual (==): = atribui um valor a uma variável, enquanto == pergunta se dois valores são iguais.

Python
estoque = 6
minimo = 10

abaixo_do_minimo = estoque < minimo
estoque_zerado = estoque == 0
tem_unidades = estoque != 0

print("Abaixo do mínimo?", abaixo_do_minimo)
print("Estoque zerado?", estoque_zerado)
print("Tem unidades?", tem_unidades)

Saída: Abaixo do mínimo? True / Estoque zerado? False / Tem unidades? True

<=Menor ou igual a (inclui a fronteira)x <= 10True

CUIDADO CONCEITUAL

Sempre verifique o limite exato: 'a partir de R$ 100' inclui o 100 (compra >= 100), enquanto 'acima de R$ 100' exige valor maior que 100 (compra > 100).

5. Operadores lógicos: and, or e not #

Muitas regras da Lojas Blue dependem de mais de uma condição ao mesmo tempo. Para conceder frete grátis, por exemplo, o pedido pode exigir que o valor seja pelo menos R$ 100 E que a entrega seja na região metropolitana.

• and (E lógico): resulta em True somente quando AMBAS as condições são verdadeiras.

• or (OU lógico): resulta em True quando PELO MENOS UMA das condições é verdadeira.

• not (NÃO lógico): inverte o valor booleano (not True vira False; not False vira True).

Python
valor_compra = 130.0
regiao_local = True
cupom_vip = False

frete_gratis = (valor_compra >= 100.0 and regiao_local) or cupom_vip
bloqueado = not regiao_local

print("Frete grátis liberado?", frete_gratis)
print("Entrega bloqueada?", bloqueado)

Saída: Frete grátis liberado? True / Entrega bloqueada? False

Condição ACondição BA and B (exige ambas)A or B (basta uma)not A (inverte A)
TrueTrueTrueTrueFalse
TrueFalseFalseTrueFalse
FalseTrueFalseTrueTrue
FalseFalseFalseFalseTrue
REGRA DE LEITURA

Escreva cada comparação completa nos dois lados do and ou do or: use nota >= 0 and nota <= 10, e nunca 'nota >= 0 and <= 10'.

6. Atualização de variáveis e expressões combinadas #

Uma operação muito frequente em algoritmos é atualizar uma variável a partir do valor que ela já possui, como saldo = saldo + entrada ou estoque = estoque - venda.

Python também oferece formas abreviadas equivalentes: estoque += 5 significa exatamente estoque = estoque + 5, e estoque -= 2 significa estoque = estoque - 2.

Python
estoque = 20
estoque = estoque + 10  # chegaram 10 unidades (passa a 30)
estoque -= 4            # saíram 4 unidades (passa a 26)

meta_atingida = estoque >= 25 and estoque % 2 == 0
print("Estoque final:", estoque)
print("Meta par atingida?", meta_atingida)

Saída: Estoque final: 26 / Meta par atingida? True
