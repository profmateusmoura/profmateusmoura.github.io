No mundo físico

Desenhe caminhos com condições nas bifurcações. Siga apenas o caminho cuja condição foi satisfeita, registrando onde os caminhos voltam a se encontrar.

1. Condições escolhem caminhos

Um aviso de reposição deve aparecer apenas quando há falta. if avalia uma condição e executa seu bloco quando o resultado é verdadeiro. A indentação mostra quais instruções pertencem ao bloco. Uma instrução que volta ao alinhamento externo será executada depois da decisão, independentemente do caminho escolhido.

2. Ler a indentação como parte da regra

A indentação não serve apenas para deixar o programa bonito: ela delimita o bloco que pertence à decisão. No exemplo, a mensagem de alerta depende da condição, mas a mensagem final está fora do bloco. Por isso, a mensagem final aparece mesmo que não exista estoque baixo.

Ao revisar um código, pergunte de quais condições cada linha depende. Uma linha deslocada pode continuar sendo sintaticamente válida e, ainda assim, executar em situações erradas. Essa é uma boa razão para prever a saída em dois casos: um que entra no bloco e outro que não entra.

Python · exemplo explicado
estoque = 8
if estoque < 5:
    print("Reposição necessária")
print("Consulta concluída")
Resultado
Consulta concluída

Como ler a execução

8 < 5 é falso, então o print indentado é ignorado. O print final não pertence ao if e executa normalmente.

3. Alternativas exclusivas e testes independentes

Uma cadeia if/elif/else escolhe no máximo um bloco: o primeiro cuja condição for verdadeira, ou else se nenhuma for. Dois if separados podem executar dois blocos. Use a cadeia quando as categorias são exclusivas; use testes independentes quando dois alertas podem coexistir. A escolha deve vir da regra do problema, não apenas de uma preferência de escrita.

4. Dois alertas ou uma classificação?

Uma loja pode precisar avisar que o estoque está baixo e que o produto está em promoção ao mesmo tempo. São informações independentes, portanto dois if podem ser apropriados. Já uma classificação em baixo, adequado ou alto pretende escolher uma única categoria, o que pede uma cadeia de alternativas.

Trocar if por elif modifica o significado do programa. Antes de escrever, decida se os resultados podem coexistir. Depois escolha condições de teste que deixem duas regras verdadeiras; esse caso revela se a estrutura permite ou impede corretamente a execução de ambos os blocos.

Python · exemplo explicado
estoque = 2
promocao = True
if estoque < 5:
    print("Estoque baixo")
if promocao:
    print("Produto em promoção")
Resultado
Estoque baixo
Produto em promoção

Como ler a execução

Cada if faz sua própria avaliação. A segunda decisão não depende de a primeira ter sido falsa.

5. Fronteiras e ordem das regras

Ao classificar estoques, escreva os casos de fronteira antes do código. Um saldo zero pode precisar de uma mensagem mais específica que um saldo apenas baixo. Se a condição geral aparecer primeiro, ela pode impedir que a condição específica seja alcançada. Teste um valor abaixo, exatamente no limite e acima dele. Esse pequeno conjunto costuma revelar erros de ordem e de inclusão da igualdade.

6. A condição específica deve ser alcançável

Se a regra diz que zero significa indisponível e valores de 1 a 4 significam estoque baixo, testar estoque < 5 primeiro em uma cadeia impediria a classificação específica de zero. A condição mais geral já incluiria esse caso.

Organize as regras de modo que cada faixa tenha um significado claro. Faça uma pequena tabela com 0, 1, 4 e 5 e escreva a categoria esperada. A regra para estoque negativo deve ser definida pelo contrato; não deixe que um valor inválido receba uma categoria por acidente. No exemplo seguinte, supomos um inteiro não negativo.

Python · exemplo explicado
estoque = 5
if estoque == 0:
    print("Indisponível")
elif estoque < 5:
    print("Baixo")
else:
    print("Adequado")
Resultado
Adequado

Como ler a execução

O zero é tratado primeiro. Como 5 não é menor que 5, ele alcança a alternativa final. A escolha de <, e não <=, define essa fronteira.
