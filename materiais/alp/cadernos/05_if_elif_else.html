1. Decisão simples com if e blocos indentados #

A instrução if avalia uma expressão booleana seguida de dois-pontos (:). Se o resultado for True, o Python executa o bloco de instruções recuado à direita (normalmente com 4 espaços de indentação). Se o resultado for False, todo esse bloco recuado é ignorado.

Após o bloco do if, as linhas que voltam à margem esquerda (sem recuo) pertencem novamente ao fluxo normal do programa e executam sempre, independentemente de a condição ter sido verdadeira ou falsa.

Python
estoque = 3
minimo = 5

if estoque < minimo:
    print("Aviso: estoque abaixo do mínimo!")
    print("Solicitar reposição ao depósito.")

print("Conferência do item finalizada.")

Saída: Aviso: estoque abaixo do mínimo! / Solicitar reposição ao depósito. / Conferência do item finalizada.

Valor de estoqueCondição estoque < 5Linhas indentadas dentro do ifLinha fora do if (na margem)
estoque = 3TrueSão executadas (imprime os 2 avisos).É executada normalmente.
estoque = 8FalseSão puladas (nenhum aviso é impresso).É executada normalmente.
REGRA DE SINTAXE

Em Python, a indentação (recuo de 4 espaços) não é apenas estética: é ela que define quais linhas estão dentro do if e quais já estão fora dele.

2. Dois caminhos alternativos com if e else #

Quando um problema exige que o programa tome uma atitude se a condição for verdadeira e outra atitude complementar caso seja falsa, acrescentamos a cláusula else:.

Em um par if / else, nunca ocorre de os dois blocos executarem juntos, nem de ambos serem ignorados: exatamente um dos dois caminhos será percorrido.

Python
saldo_estoque = 10
pedido = 14

if pedido <= saldo_estoque:
    saldo_estoque = saldo_estoque - pedido
    print("Venda autorizada! Saldo restante:", saldo_estoque)
else:
    print("Venda recusada: estoque insuficiente.")
    print("Saldo mantido em:", saldo_estoque)

Saída: Venda recusada: estoque insuficiente. / Saldo mantido em: 10

Valor de pedidoTeste pedido <= 10Bloco executadoValor final de saldo_estoque
pedido = 6TrueBloco do if (autoriza e desconta)4
pedido = 10 (fronteira)TrueBloco do if (autoriza e zera saldo)0
pedido = 14FalseBloco do else (recusa e preserva saldo)10

3. Múltiplas faixas com if, elif e else #

Quando precisamos classificar um valor entre três ou mais categorias (como faixas de desconto por valor de compra), usamos a cadeia if / elif / else. A palavra elif é a abreviação de else if ('senão, se...').

O Python testa as condições de cima para baixo. Assim que encontra a PRIMEIRA condição verdadeira, executa o bloco correspondente e pula todos os elif e else restantes da cadeia. Por isso, ao organizar faixas em ordem decrescente (primeiro >= 200, depois >= 100, depois >= 50), cada elif já sabe implicitamente que o valor é menor que o limite anterior.

Python
valor_compra = 140.0

if valor_compra >= 200.0:
    desconto = 25
elif valor_compra >= 100.0:
    desconto = 15
elif valor_compra >= 50.0:
    desconto = 5
else:
    desconto = 0

print(f"Compra de R$ {valor_compra:.2f} -> Desconto de R$ {desconto}")

Saída: Compra de R$ 140.00 -> Desconto de R$ 15

valor_compra1º teste (>= 200)2º teste (>= 100)3º teste (>= 50)Ramo executado e desconto
250.0True(não é testado)(não é testado)if → desconto = 25
140.0FalseTrue(não é testado)1º elif → desconto = 15
75.0FalseFalseTrue2º elif → desconto = 5

4. Diferença crítica: vários if independentes vs. elif #

Um erro muito comum é escrever vários if separados quando a intenção era escolher apenas uma faixa exclusiva. Quando escrevemos dois if consecutivos, o segundo if é uma estrutura nova e independente: ele será testado mesmo que o primeiro if tenha sido verdadeiro!

Use if independentes apenas quando mais de uma regra puder ser aplicada cumulativamente ao mesmo caso. Para faixas mutuamente exclusivas, use sempre if / elif / else.

Python
estoque = 3
alertas = 0

# Dois if independentes: ambos são testados!
if estoque < 10:
    alertas = alertas + 1
if estoque < 5:
    alertas = alertas + 1

print("Total de alertas acumulados:", alertas)

Saída: Total de alertas acumulados: 2

EstruturaComportamento quando a 1ª condição é TrueQuando escolher
if ... elif ... elseExecuta apenas o 1º ramo e ignora os demais.Classificar em uma única faixa (Ouro, Prata ou Bronze).
if ... seguido de outro if ...Executa o 1º if e também testa o 2º if.Regras independentes que podem somar efeitos (ex.: bônus de meta + bônus de assiduidade).

5. Condições compostas e cuidados com fronteiras #

Muitas decisões exigem combinar comparações com and e or ou verificar valores exatamente no limite entre duas faixas (valores de fronteira).

Cuidado com a ordem das faixas: se em um if/elif você testar primeiro if compra >= 50: antes de elif compra >= 200:, uma compra de R$ 250 entrará logo no primeiro ramo (>= 50) e nunca chegará ao desconto maior!

Python
total_compra = 100.0
cliente_cadastrado = True

if total_compra >= 100.0 and cliente_cadastrado:
    frete = 0.0
elif total_compra >= 100.0 or cliente_cadastrado:
    frete = 9.90
else:
    frete = 19.90

print(f"Frete calculado: R$ {frete:.2f}")

Saída: Frete calculado: R$ 0.00

CUIDADO CONCEITUAL

Ao encadear faixas com >= (maior ou igual), ordene sempre do maior limite para o menor (200, depois 100, depois 50). Se ordenar do menor para o maior usando <, comece pelo menor (< 50, depois < 100, depois < 200).

6. Decisões aninhadas (if dentro de if) #

Às vezes, uma segunda pergunta só faz sentido depois que uma primeira condição principal foi confirmada. Por exemplo: primeiro verificamos se há estoque disponível; somente se houver estoque, verificamos a forma de pagamento para calcular o valor final.

Colocar um if/else recuado dentro de outro if/else chama-se aninhamento. Mantenha o recuo consistente (4 espaços para o primeiro nível, 8 espaços para o nível interno).

Python
estoque = 5
forma_pagamento = "PIX"
preco = 100.0

if estoque > 0:
    if forma_pagamento == "PIX":
        valor_final = preco * 0.90
    else:
        valor_final = preco
    print(f"Item disponível. Total: R$ {valor_final:.2f}")
else:
    print("Produto indisponível no momento.")

Saída: Item disponível. Total: R$ 90.00
