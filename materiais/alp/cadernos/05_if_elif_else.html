Entenda a ideia

Condições escolhem caminhos

Um aviso de reposição deve aparecer apenas quando há falta. if avalia uma condição e executa seu bloco quando o resultado é verdadeiro. A indentação mostra quais instruções pertencem ao bloco. Uma instrução que volta ao alinhamento externo será executada depois da decisão, independentemente do caminho escolhido.

Alternativas exclusivas e testes independentes

Uma cadeia if/elif/else escolhe no máximo um bloco: o primeiro cuja condição for verdadeira, ou else se nenhuma for. Dois if separados podem executar dois blocos. Use a cadeia quando as categorias são exclusivas; use testes independentes quando dois alertas podem coexistir. A escolha deve vir da regra do problema, não apenas de uma preferência de escrita.

Fronteiras e ordem das regras

Ao classificar estoques, escreva os casos de fronteira antes do código. Um saldo zero pode precisar de uma mensagem mais específica que um saldo apenas baixo. Se a condição geral aparecer primeiro, ela pode impedir que a condição específica seja alcançada. Teste um valor abaixo, exatamente no limite e acima dele. Esse pequeno conjunto costuma revelar erros de ordem e de inclusão da igualdade.

Erros para observar

Misturar tabulações e espaços; ordenar faixas de modo que um ramo nunca seja alcançado; esquecer o empate; fazer a operação perigosa antes da verificação.

Um exemplo acompanhado

Leia o código antes de avançar. Cada passo explica uma mudança ou decisão. A simulação tem uma sequência fixa; os arquivos Python permitem experimentar outras entradas.

estoque = 0
if estoque == 0:
    print("Sem estoque")
elif estoque < 5:
    print("Estoque baixo")
else:
    print("Estoque suficiente")

05 — Decisão aninhadaBaixar este exemplo .py
# 05 — Decisão aninhada
# Objetivo: Proteger uma operação com uma condição anterior.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: A divisão só ocorre no ramo em que o divisor é diferente de zero.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   8
#   2
# Confira na saída: 'Quociente: 4.0'

numerador = float(input("Numerador: "))
divisor = float(input("Divisor: "))
if divisor == 0:
    print("Não é possível dividir por zero.")
else:
    resultado = numerador / divisor
    if resultado > 0:
        print("Resultado positivo")
    else:
        print("Resultado zero ou negativo")
    print("Quociente:", resultado)
06 — Maior entre três valoresBaixar este exemplo .py
# 06 — Maior entre três valores
# Objetivo: Manter um candidato sem coleções.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: Os if independentes permitem comparar o candidato duas vezes.
# Como estudar: preveja a saída, execute e altere um valor por vez.
# Execução guiada: digite uma entrada por solicitação, nesta ordem:
#   -8
#   -2
#   -5
# Confira na saída: 'Maior: -2'

a = int(input("Primeiro: "))
b = int(input("Segundo: "))
c = int(input("Terceiro: "))
# Começamos com um valor real, não com zero arbitrário.
maior = a
if b > maior:
    maior = b
if c > maior:
    maior = c
# Em caso de empate, o valor máximo continua correto.
print("Maior:", maior)

# Alerta de estoque — cenário didático Lojas Blue
# Objetivo: Classificar um saldo por comparação com o mínimo.
# Pré-requisito: tópicos anteriores e exemplos anteriores deste tópico.

# Confira na saída: 'Sugestão até o mínimo: 4'
# Sem entrada interativa.

# Recorte da posição unidade 1, produto 4.

    print("Estoque crítico")

    print("Sem falta até o mínimo")
# Igualdade com o mínimo pertence ao segundo caminho.
