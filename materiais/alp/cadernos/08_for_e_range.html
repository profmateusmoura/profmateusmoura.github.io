Entenda a ideia

Repetição sobre um intervalo numérico

Em ALP, for percorre os números fornecidos por range. range(3) fornece 0, 1 e 2: o limite final fica de fora. Quando o início é informado, range(2, 5) fornece 2, 3 e 4. Não é necessário criar uma lista para percorrer esses números. Preveja o primeiro e o último valor antes de executar.

O passo precisa apontar para o limite

O terceiro argumento controla o avanço. Um passo negativo permite contagem decrescente, mas o início e o fim precisam ser coerentes com essa direção. range(5, 0, -2) fornece 5, 3 e 1. Um intervalo pode não produzir nenhum valor; isso é diferente de um erro. O passo zero, por outro lado, não é permitido.

Laços aninhados multiplicam repetições

Para cada execução do laço externo, o laço interno percorre todo o seu intervalo. Essa organização pode imprimir tabelas ou padrões retangulares. Registre o par de contadores em cada passagem para evitar confundir a sequência. Se a tarefa exige apenas um acumulador global, inicialize-o antes dos dois laços; se exige um total por linha, reinicialize-o dentro do externo e antes do interno.

Erros para observar

Excluir o último valor sem querer; usar passo na direção incompatível; atualizar manualmente a variável esperando controlar o próximo valor do for; colocar a quebra de linha no laço errado.

O mesmo acumulador com while e forBaixar este exemplo .py
# O mesmo acumulador com while e for
# Execução: python 08_for_e_range/exemplos/09_comparar_while_e_for.py
# Confira na saída: 'Com for: 10'
# Preveja o estado dos dados antes de executar; depois altere um caso de fronteira.

limite = 4
soma_while = 0
atual = 1
# No while, o programa inicializa e atualiza o estado de controle.
while atual <= limite:
    soma_while += atual
    atual += 1
soma_for = 0
# No for, range fornece os valores; limite + 1 inclui o último pretendido.
for numero in range(1, limite + 1):
    soma_for += numero
print("Com while:", soma_while)
print("Com for:", soma_for)
# Limite zero produz soma zero nas duas versões, sem executar os corpos.
# A escolha é pelo tipo de controle necessário, não pelo resultado da soma.

# Conferência de três posições — cenário didático Lojas Blue
# Objetivo: Contar saldos críticos sem armazenar histórico.
# Pré-requisito: tópicos anteriores e exemplos anteriores deste tópico.
# Estude: preveja o resultado, execute e altere um dado por vez.
# Confira na saída: 'Posições críticas: 1'
# Entradas guiadas, uma por solicitação:
#   18
#   4
#   10

    saldo = int(input(f"Saldo não negativo da posição {ordem}: "))
    if saldo < minimo:
        criticos += 1
print("Posições críticas:", criticos)
# Saldos de unidades diferentes são consumidos um de cada vez.
