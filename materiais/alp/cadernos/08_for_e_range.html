No mundo físico

Numere posições de uma tarefa antes de executá-la. O for usa o intervalo para fornecer cada número; o corpo descreve o trabalho feito nessa passagem.

1. Repetição sobre um intervalo numérico

Em ALP, for percorre os números fornecidos por range. range(3) fornece 0, 1 e 2: o limite final fica de fora. Quando o início é informado, range(2, 5) fornece 2, 3 e 4. Não é necessário criar uma lista para percorrer esses números. Preveja o primeiro e o último valor antes de executar.

2. Entender os três argumentos do intervalo

range pode receber apenas o limite, início e limite, ou início, limite e passo. Com um argumento, o início é zero e o passo é um. O limite final nunca é incluído. Para uma contagem crescente que deve alcançar um inteiro limite, é comum usar limite + 1 como fronteira exclusiva.

Não conclua que o último valor será sempre limite menos um: essa afirmação só descreve certos intervalos de passo um. Com passos maiores, o último valor depende de onde a sequência chega antes de atravessar a fronteira. Escreva os primeiros termos para conferir a direção.

Python · exemplo explicado
for numero in range(1, 4):
    print(numero)
Resultado
1
2
3

Como ler a execução

O último valor exibido é 3 porque 4 é a fronteira exclusiva. A variável numero recebe cada valor fornecido pelo intervalo.

3. O passo precisa apontar para o limite

O terceiro argumento controla o avanço. Um passo negativo permite contagem decrescente, mas o início e o fim precisam ser coerentes com essa direção. range(5, 0, -2) fornece 5, 3 e 1. Um intervalo pode não produzir nenhum valor; isso é diferente de um erro. O passo zero, por outro lado, não é permitido.

4. Um intervalo decrescente também exclui o fim

Em uma contagem regressiva, o passo precisa ser negativo. Para incluir zero, a fronteira exclusiva pode ser -1. Se início e fim contradizem a direção do passo, o intervalo pode ficar vazio. Não acrescente condições dentro do corpo para corrigir um intervalo que já foi definido incorretamente.

Separar a geração dos números do trabalho feito em cada número torna o raciocínio mais simples. Primeiro confirme quais valores range oferece. Só depois analise o print, a conta ou a decisão dentro do corpo. Um for não altera sozinho o significado de seu limite para ajustá-lo ao enunciado.

Python · exemplo explicado
for numero in range(3, -1, -1):
    print(numero)
Resultado
3
2
1
0

Como ler a execução

A sequência avança para baixo. O -1 serve de fronteira e não aparece na saída.

5. Laços aninhados multiplicam repetições

Para cada execução do laço externo, o laço interno percorre todo o seu intervalo. Essa organização pode imprimir tabelas ou padrões retangulares. Registre o par de contadores em cada passagem para evitar confundir a sequência. Se a tarefa exige apenas um acumulador global, inicialize-o antes dos dois laços; se exige um total por linha, reinicialize-o dentro do externo e antes do interno.

6. Laço externo escolhe a linha; interno percorre a linha

Em um padrão de duas linhas e três colunas, cada passagem do laço externo inicia uma linha completa. O interno escreve três símbolos. Depois dele, uma chamada de print sem argumentos encerra a linha atual. A colocação dessa quebra é tão importante quanto os limites.

Se a quebra estivesse dentro do laço interno, cada símbolo apareceria em uma linha própria. Se não existisse, as duas linhas seriam juntadas. É um exemplo de como o controle de saída do primeiro caderno se combina com o controle de repetição, sem precisar de listas ou outras coleções.

Python · exemplo explicado
for linha in range(2):
    for coluna in range(3):
        print("*", end="")
    print()
Resultado
***
***

Como ler a execução

O print do símbolo executa seis vezes. O print de encerramento executa duas: uma para cada linha externa.
