1. Como funciona a repetição com while #

A estrutura while condicao: funciona como um if que volta ao topo. Antes de cada repetição, o Python avalia a condição booleana. Se for True, executa todo o bloco indentado e, ao terminar a última linha do bloco, volta automaticamente ao cabeçalho while para testar a condição de novo.

Quando a condição finalmente resulta em False, o Python pula o bloco indentado e segue para a primeira linha fora do while. Se a condição já for False logo na primeira verificação, o corpo do while executa zero vezes.

Python
etiqueta = 1

while etiqueta <= 3:
    print("Imprimindo etiqueta nº", etiqueta)
    etiqueta = etiqueta + 1

print("Impressão concluída. Valor final de etiqueta:", etiqueta)

Saída: Imprimindo etiqueta nº 1 / Imprimindo etiqueta nº 2 / Imprimindo etiqueta nº 3 / Impressão concluída. Valor final de etiqueta: 4

2. As três partes de um while e o perigo do laço infinito #

Para que um laço while funcione com segurança, ele precisa coordenar três elementos sobre a mesma variável de controle:

1. Inicialização antes do while (dar um valor inicial à variável).

2. Condição de continuidade no cabeçalho while.

3. Atualização dentro do bloco (modificar a variável em direção à parada).

Se esquecermos a atualização dentro do bloco (ou se a deixarmos fora da indentação do while), a variável nunca mudará, a condição continuará True para sempre e o programa ficará preso em um laço infinito.

Python
# Contagem regressiva de caixas restantes para conferência:
restantes = 4                 # 1. Inicialização

while restantes > 0:          # 2. Condição
    print("Faltam conferir:", restantes)
    restantes = restantes - 1 # 3. Atualização rumo a 0

print("Todos os lotes foram conferidos!")

Saída: Faltam conferir: 4 / Faltam conferir: 3 / Faltam conferir: 2 / Faltam conferir: 1 / Todos os lotes foram conferidos!

ATENÇÃO

Se o seu programa travar em um laço infinito no terminal da IDE, pressione Ctrl + C para interromper a execução e verifique se a linha de atualização está recuada dentro do while.

3. Contadores e acumuladores #

Em problemas de fechamento de caixa, costumamos usar dois papéis de variáveis dentro do mesmo laço:

• Contador: soma uma constante fixa (geralmente +1) a cada repetição ou a cada item que cumpre uma condição.

• Acumulador (somatório): começa em 0 antes do laço e soma valores variáveis (como o preço de cada produto vendido) a cada volta.

Python
item = 1
soma_vendas = 0.0

while item <= 3:
    preco = item * 15.0
    soma_vendas = soma_vendas + preco
    print(f"Item {item}: R$ {preco:.2f} | Subtotal acumulado: R$ {soma_vendas:.2f}")
    item = item + 1

print(f"Total final das 3 vendas: R$ {soma_vendas:.2f}")

Saída: Item 1: R$ 15.00 | Subtotal acumulado: R$ 15.00 / Item 2: R$ 30.00 | Subtotal acumulado: R$ 45.00 / Item 3: R$ 45.00 | Subtotal acumulado: R$ 90.00 / Total final das 3 vendas: R$ 90.00

Contador0 ou 1cont = cont + 1Contar quantas voltas ou quantos itens atenderam a um critério.
Acumulador (soma)0 ou 0.0soma = soma + valor_atualSomar preços, pesos, quantidades ou pontos ao longo das repetições.
ERRO CLÁSSICO

Nunca inicialize soma = 0 DENTRO do bloco do while! Se fizer isso, o acumulador será zerado a cada volta e guardará apenas o último valor.

4. Repetição controlada por valor sentinela #

Muitas vezes não sabemos de antemão quantos produtos um cliente vai comprar: podem ser 2 itens, 15 itens ou nenhum. Nesses casos, definimos um valor especial chamado sentinela (por exemplo, digitar 0 para encerrar).

O padrão clássico de leitura com sentinela faz a primeira leitura ANTES do while e a leitura seguinte na ÚLTIMA LINHA dentro do while. Assim, se o usuário digitar 0 logo de início, o laço nem entra; e quando digitar 0 após vários produtos, o 0 encerra o while imediatamente sem ser somado nem contado como produto!

Python
# Simulação com valores lidos: 25, depois 15, depois 0 (sentinela)
# Em um programa interativo:
# valor = int(input("Valor do item (0 para encerrar): "))
valor = 25
soma = 0
itens = 0

while valor != 0:
    soma = soma + valor
    itens = itens + 1
    # Próxima leitura no fim do bloco:
    if itens == 1:
        valor = 15
    else:
        valor = 0

print("Itens registrados:", itens, "| Soma R$:", soma)

Saída: Itens registrados: 2 | Soma R$: 40

5. Contagem condicional (if dentro de while) #

Podemos colocar uma estrutura if/else dentro do bloco do while para filtrar ou classificar cada elemento processado. Por exemplo, ao ler 4 vendas, podemos contar separadamente quantas foram de alto valor (>= 100) e quantas foram comuns.

Python
venda_num = 1
altas = 0

while venda_num <= 4:
    valor = venda_num * 40  # gera 40, 80, 120, 160
    if valor >= 100:
        altas = altas + 1
    venda_num = venda_num + 1

print("Vendas a partir de R$ 100:", altas)

Saída: Vendas a partir de R$ 100: 2

6. Média após laço com proteção contra divisão por zero #

Em um programa com sentinela, o usuário pode digitar 0 logo na primeira leitura. Nesse caso, o contador de itens válidos permanece 0.

Antes de calcular media = soma / quantidade após o término do while, sempre verifique if quantidade > 0: para evitar o erro ZeroDivisionError.

Python
soma = 0.0
quantidade = 0
# Suponha que o caixa foi encerrado imediatamente com 0 vendas:

if quantidade > 0:
    media = soma / quantidade
    print(f"Ticket médio: R$ {media:.2f}")
else:
    print("Nenhuma venda registrada no período.")

Saída: Nenhuma venda registrada no período.
