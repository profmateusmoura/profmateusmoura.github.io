Entenda a ideia

Nomear uma tarefa e definir um contrato

Uma função reúne instruções para uma responsabilidade. def define a função; a chamada solicita sua execução. Parâmetros são os nomes usados na definição; argumentos são os valores fornecidos na chamada. Antes de escrever o corpo, declare quais entradas são aceitas, o que a função faz e o que devolve. Uma docstring registra esse contrato perto do código.

Mostrar e devolver são operações diferentes

print produz uma mensagem para quem observa a execução. return entrega um valor para quem chamou a função e encerra a chamada. Uma função que apenas imprime o dobro não permite que o chamador use esse dobro em outra conta. Quando nenhum return com valor é executado, o resultado da chamada é None. Separe cálculo e apresentação para facilitar a reutilização.

Cada chamada tem seu próprio trabalho

Uma variável local pertence à execução da função. Não confunda mudar um nome local com atualizar uma variável externa de mesmo nome. Faça chamadas consecutivas com argumentos diferentes e confira se resultados anteriores não são acumulados indevidamente. Neste curso, mantenha os retornos dos exemplos no domínio escalar e deixe coleções para PED.

Erros para observar

Imprimir um cálculo quando o chamador precisa do retorno; esquecer return em um caminho; depender de variáveis globais; deixar a docstring prometer uma validação que a função não faz.

# Objetivo: Documentar a entrada aceita e os limites.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: Cada caminho retorna um único texto.
# Como estudar: preveja a saída, execute e altere um valor por vez.

def classificar_nota(nota):
    """Receba uma nota numérica finita e retorne sua classificação.

    Retorne inválida fora da faixa, aprovada a partir de 7,
    recuperação a partir de 5 e reprovada abaixo de 5.
    """
    if nota < 0 or nota > 10:
        return "inválida"
    if nota >= 7:
        return "aprovada"
    if nota >= 5:
        return "recuperação"
    return "reprovada"

# Cada return encerra imediatamente a chamada atual.
print("Nota 7:", classificar_nota(7))
print("Nota 5:", classificar_nota(5))
print("Nota -1:", classificar_nota(-1))

# Objetivo: Encapsular um laço sem entrada ou saída interna.
# Pré-requisitos: exemplos anteriores deste tópico e tópicos anteriores.
# Observe: O retorno é um único inteiro, nunca uma coleção.

def calcular_fatorial(numero):
    """Retorne numero!; numero deve ser inteiro maior ou igual a zero."""
    produto = 1
    for fator in range(2, numero + 1):
        produto *= fator
    return produto

# O chamador assume a responsabilidade de cumprir o contrato.
for numero in range(6):
    print(f"{numero}! = {calcular_fatorial(numero)}")
# O produto local é reiniciado em cada chamada.

def ler_inteiro_positivo(mensagem):
    """Solicite até obter um inteiro positivo e retorne esse inteiro.

    mensagem é o texto do convite; formato e faixa inválidos são recusados.
    """
    while True:
        try:
            numero = int(input(mensagem))
        except ValueError:
            print("Digite um inteiro.")
            continue
        if numero > 0:
            return numero  # Encerra a função e seu laço.
        print("O inteiro deve ser positivo.")

quantidade = ler_inteiro_positivo("Quantidade: ")
print("Dobro da quantidade:", quantidade * 2)
# Cálculos continuam fora da função de leitura.

Usar o retorno de uma função em outraBaixar este exemplo .py
# Usar o retorno de uma função em outra
# Execução: python 11_funcoes/exemplos/12_compor_funcoes.py
# Confira na saída: 'Por etapas: 67.23'
# Preveja o estado dos dados antes de executar; depois altere um caso de fronteira.

def calcular_bruto(preco, quantidade):
    """Retorne total bruto para preço não negativo e quantidade positiva."""
    return preco * quantidade

def aplicar_desconto(total, taxa):
    """Retorne total após taxa percentual válida entre zero e cem."""
    return total - total * taxa / 100

# A expressão mais interna é calculada antes de aplicar_desconto receber dados.
final_direto = aplicar_desconto(calcular_bruto(24.9, 3), 10)
# A decomposição com variável intermediária facilita acompanhar o mesmo fluxo.
bruto = calcular_bruto(24.9, 3)
final_por_etapas = aplicar_desconto(bruto, 10)
print(f"Direto: {final_direto:.2f}")
print(f"Por etapas: {final_por_etapas:.2f}")
# Nenhuma função precisou ler, imprimir ou acessar o estado interno da outra.
Função de reposição — cenário didático Lojas BlueBaixar este exemplo .py
# Função de reposição — cenário didático Lojas Blue
# Objetivo: Retornar uma sugestão sem ler ou exibir dentro do cálculo.
# Pré-requisito: tópicos anteriores e exemplos anteriores deste tópico.
# Estude: preveja o resultado, execute e altere um dado por vez.
# Confira na saída: 'Produto 4, unidade 1: 4'
# Sem entrada interativa.

def sugerir_reposicao(saldo, minimo):
    """Retorne a falta até o mínimo para dois inteiros não negativos."""
    if saldo < minimo:
        return minimo - saldo
    return 0

# A função retorna um inteiro, sem listas ou múltiplos retornos.
print("Produto 4, unidade 1:", sugerir_reposicao(4, 8))
print("Produto 1, unidade 1:", sugerir_reposicao(18, 10))
