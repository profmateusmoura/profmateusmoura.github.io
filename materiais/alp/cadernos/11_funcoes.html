1. Definindo e chamando funções com def #

Uma função é um bloco de código nomeado que realiza uma tarefa bem definida. Criamos uma função com a palavra-chave def seguida do nome da função, parênteses () e dois-pontos (:). O corpo da função fica indentado logo abaixo.

Atenção à ordem temporal: quando o Python lê um bloco def, ele apenas registra a função na memória — o corpo NÃO é executado naquele instante. As instruções internas só rodam quando fazemos a chamada da função usando seu nome seguido de parênteses: exibir_cabecalho().

Python
def exibir_cabecalho():
    print("==============================")
    print("   LOJAS BLUE - CAIXA RÁPIDO  ")
    print("==============================")

print("Iniciando terminal...")
exibir_cabecalho()
print("Operação concluída.")

Saída: Iniciando terminal... / ============================== / LOJAS BLUE - CAIXA RÁPIDO / ============================== / Operação concluída.

MomentoLinha no arquivoO que acontece
1def exibir_cabecalho(): ...Python guarda a definição da função; nada é impresso ainda.
2print("Iniciando terminal...")Imprime 'Iniciando terminal...'.
3exibir_cabecalho()Desvia o fluxo para o corpo da função, imprime as 3 linhas e retorna.
4print("Operação concluída.")Retoma o programa após a chamada.

2. Parâmetros e argumentos: enviando dados para a função #

Para que uma função trabalhe com valores diferentes a cada chamada, declaramos parâmetros dentro dos parênteses do def. Quando chamamos a função passando argumentos, cada parâmetro recebe o valor do argumento correspondente na mesma ordem posicional.

Assim, a mesma função exibir_etiqueta(produto, preco) pode imprimir a etiqueta de dezenas de itens diferentes.

Python
def exibir_etiqueta(produto, preco):
    print(f"[Etiqueta Blue] {produto}: R$ {preco:.2f}")

exibir_etiqueta("Shampoo Neutro", 24.90)
exibir_etiqueta("Protetor Solar", 59.00)

Saída: [Etiqueta Blue] Shampoo Neutro: R$ 24.90 / [Etiqueta Blue] Protetor Solar: R$ 59.00

Argumentos (2ª chamada)Na chamada da função"Protetor Solar" e 59.00

3. Devolvendo resultados com return (e a diferença para print) #

Na maioria dos algoritmos, queremos que uma função calcule um resultado e o devolva para o ponto onde foi chamada, para que possamos guardá-lo em uma variável, somá-lo a outro valor ou passá-lo para outra função. Quem faz isso é a instrução return.

Não confunda return com print():

• print() apenas escreve caracteres na tela e não entrega valor nenhum ao código chamador.

• return encerra imediatamente a execução da função e entrega o valor calculado no lugar da chamada. Se uma função terminar sem executar return, ela devolve automaticamente o valor especial None.

Python
def aplicar_desconto(preco, percentual):
    desconto = preco * (percentual / 100.0)
    valor_final = preco - desconto
    return valor_final

item_com_desconto = aplicar_desconto(100.0, 15.0)
frete = 10.0
total_pedido = item_com_desconto + frete
print(f"Item: R$ {item_com_desconto:.2f} | Com frete: R$ {total_pedido:.2f}")

Saída: Item: R$ 85.00 | Com frete: R$ 95.00

O que a função tem no finalValor recebido por x = funcao()É possível somar x + 10 depois?
return valor_finalO número calculado (ex.: 85.0)Sim! (85.0 + 10 = 95.0)
Apenas print(valor_final) (sem return)None (ausência de valor)Não! (None + 10 gera TypeError)

4. Escopo local: variáveis de dentro não vazam para fora #

Os parâmetros e as variáveis criadas dentro de uma função possuem escopo local: eles nascem quando a função é chamada e deixam de existir assim que a função retorna.

Se uma função criar uma variável local chamada taxa = 99, ela não alterará uma variável taxa = 10 que exista fora da função. Essa independência é fundamental para que possamos chamar funções sem medo de estragar variáveis do restante do programa.

Python
def simular_taxa():
    taxa = 99
    return taxa

taxa = 10
simulado = simular_taxa()
print("Taxa no programa principal:", taxa)
print("Valor retornado pela simulação:", simulado)

Saída: Taxa no programa principal: 10 / Valor retornado pela simulação: 99

5. Funções booleanas (predicados) e múltiplos return #

Funções que devolvem True ou False (como eh_estoque_critico(qtd, minimo) ou eh_par(n)) deixam as condições de if e while muito mais legíveis.

Além disso, uma função pode conter um if/elif/else em que cada ramo possui seu próprio return. Como return encerra a função na hora, o primeiro ramo verdadeiro já devolve a resposta final.

Python
def eh_estoque_critico(atual, minimo):
    return atual < minimo

def classificar_bonus(vendas):
    if vendas >= 1000.0:
        return 150.0
    elif vendas >= 500.0:
        return 60.0
    else:
        return 0.0

if eh_estoque_critico(3, 5):
    print("Reposição urgente! Bônus do vendedor:", classificar_bonus(750.0))

Saída: Reposição urgente! Bônus do vendedor: 60.0

6. Parâmetros com valor padrão e documentação (docstring) #

Podemos atribuir um valor padrão a um parâmetro na definição (como aliquota=0.10). Se quem chamar a função omitir esse argumento, o valor padrão será utilizado; se informar outro valor, o valor informado prevalecerá.

Também é uma excelente prática descrever o contrato da função em uma docstring (texto entre três aspas duplas """...""" na primeira linha do bloco def).

Python
def calcular_imposto(valor_base, aliquota=0.10):
    """Calcula e retorna o imposto sobre valor_base usando a aliquota informada."""
    return valor_base * aliquota

print("Imposto padrão (10%):", calcular_imposto(200.0))
print("Imposto especial (5%):", calcular_imposto(200.0, 0.05))

Saída: Imposto padrão (10%): 20.0 / Imposto especial (5%): 10.0
