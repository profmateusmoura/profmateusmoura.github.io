Como estudar este caderno

Leia as seções na ordem. Cada uma desenvolve uma ideia, mostra como ela aparece no código e explica o resultado. Os códigos curtos do texto são exemplos de leitura; o pacote ZIP reúne os programas completos e os exercícios para praticar depois.

Antes de executar um código, preveja o que será exibido. Compare a previsão com a explicação e observe qual instrução produz cada mudança. Não é necessário acertar de primeira: localizar a diferença faz parte do estudo.

No mundo físico

Uma tarefa pode receber dados e devolver uma resposta. Entregar a resposta a outra pessoa é diferente de apenas anunciá-la em voz alta: essa é a distinção entre retorno e apresentação.

1. Nomear uma tarefa e definir um contrato

Uma função reúne instruções para uma responsabilidade. def define a função; a chamada solicita sua execução. Parâmetros são os nomes usados na definição; argumentos são os valores fornecidos na chamada. Antes de escrever o corpo, declare quais entradas são aceitas, o que a função faz e o que devolve. Uma docstring registra esse contrato perto do código.

2. Definir não é executar; chamar cria uma execução

Quando Python encontra def, ele registra uma função. O corpo será executado quando houver uma chamada. Essa separação permite definir uma tarefa uma vez e utilizá-la várias vezes com valores diferentes. O argumento de cada chamada é associado ao parâmetro daquela execução.

Leia o programa em duas camadas: primeiro identifique as definições disponíveis; depois acompanhe as chamadas que realmente acontecem. Uma função bem escrita, mas nunca chamada, não realiza sua tarefa durante aquela execução. Um return encerra apenas a chamada em andamento e devolve o controle ao ponto que a solicitou.

Python · exemplo explicado
def saudacao(nome):
    """Exibe uma saudação para o nome recebido."""
    print(f"Olá, {nome}")

saudacao("Ana")
saudacao("Bia")
Resultado
Olá, Ana
Olá, Bia

Como ler a execução

O mesmo corpo executa duas vezes. O parâmetro nome recebe Ana na primeira chamada e Bia na segunda.

3. Mostrar e devolver são operações diferentes

print produz uma mensagem para quem observa a execução. return entrega um valor para quem chamou a função e encerra a chamada. Uma função que apenas imprime o dobro não permite que o chamador use esse dobro em outra conta. Quando nenhum return com valor é executado, o resultado da chamada é None. Separe cálculo e apresentação para facilitar a reutilização.

4. Escopo local evita confundir nomes iguais

Um nome usado dentro de uma função pode ser local a ela. Atribuir a esse nome não significa alterar uma variável externa que tem a mesma grafia. Não dependa dessa coincidência de nomes para transportar informação: passe argumentos para entrar e use retorno para sair quando houver um resultado.

Uma forma simples de conferir essa independência é exibir o nome local durante a chamada e o nome externo depois dela. Essa experiência ajuda a explicar por que uma função deve declarar suas dependências no contrato, em vez de buscar valores espalhados pelo programa.

Python · exemplo explicado
valor = 10
def mostrar():
    """Exibe um valor local de demonstração."""
    valor = 3
    print(valor)

mostrar()
print(valor)
Resultado
3
10

Como ler a execução

A atribuição dentro da função cria seu valor local. O nome externo permanece associado a 10.

5. Cada chamada tem seu próprio trabalho

Uma variável local pertence à execução da função. Não confunda mudar um nome local com atualizar uma variável externa de mesmo nome. Faça chamadas consecutivas com argumentos diferentes e confira se resultados anteriores não são acumulados indevidamente. Neste curso, mantenha os retornos dos exemplos no domínio escalar e deixe coleções para PED.

6. Retornos antecipados e parâmetros padrão

Uma função pode devolver um resultado assim que uma regra decisiva for satisfeita. As instruções posteriores não executam naquela chamada. Por isso, um return dentro de um laço precisa ser avaliado com cuidado: ele pode encerrar a função após a primeira passagem, mesmo que a tarefa exija processar todas as entradas.

Um parâmetro padrão oferece um argumento quando o chamador o omite. Em ALP, usamos padrões escalares simples. A escolha do padrão faz parte do contrato, e uma chamada explícita deve continuar possível. Teste tanto a chamada que usa o padrão quanto a que fornece outro valor.

Python · exemplo explicado
def total(preco, quantidade=1):
    """Calcula preço vezes quantidade, usando uma unidade por padrão."""
    return preco * quantidade

print(total(10))
print(total(10, 3))
Resultado
10
30

Como ler a execução

Na primeira chamada, quantidade assume 1. Na segunda, o argumento 3 substitui esse padrão para aquela chamada.

Um exemplo acompanhado

Leia o código antes de avançar. Cada passo explica uma mudança ou decisão. A simulação tem uma sequência fixa; os arquivos Python permitem experimentar outras entradas.

def dobro(valor):
    """Devolve o dobro do número recebido."""
    return valor * 2

resultado = dobro(4)
print(resultado + 3)
Conferir a saída
11
